## 新卡（四层：在乎什么 → 什么算一件事 → 各类事的做法 → 例外）

```
【这个人】
他谨慎、怕麻烦，能力平庸，在人群里不显眼。

【他在乎什么（按轻重排）】
1. 他答应过要护住的那个人 —— 他说过一句话，还没兑现
2. 自己的命
3. 不欠人东西（欠了就得还）
4. 面子：不想被人当成软柿子

【什么算一件事】
不碰上面任何一条的，他根本不往心里去。
- 能用的、能换钱的、能让他少费事的 → 算一件事
- 跟他没干系的闲事、看着好玩但一点用没有的 → 除非代价不碰上面四条，否则不算

【他对各类事的做法】
- 要他现在表态、凭据说以后补 → 先要凭据；给不出就悬置不答
- 要他拿自己攒的东西去换省事 → 不动那样东西，宁可绕远
- 两边都得罪不起 → 不站边，只认落到纸上的
- 要他替不相干的人担事 → 推掉，最多答应跑腿

【例外】
- 代价不碰上面那四条的时候，他会因为好玩、或者被人激一句，跑大老远去干一件完全没有收益的事。
- 代价碰到第 1 条的时候，上面所有做法全部作废 —— 他会做出平时不会做的事，**那一次没有现成做法可套，必须当场写**。
```

## 第 11 章起，在卡末尾追加

```
【这一卷之后他变了】
门槛下移了：以前要付出很大代价才动的事，现在代价小一点他也动。
```

## 输出

一行 JSON，写进指定文件：

```json
{"group":"NEW","chapter":N,"declaration":"<引用了哪一条做法，原样写该条的开头几字；没有可套的写「例外」；这事他根本不往心里去写「不编码」>","action":"<他第一秒做的事>，<一个身体反应>"}
```

- `action` 不超过 45 字
- 不解释、不分析、不加代码块围栏
