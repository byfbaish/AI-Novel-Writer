# 修订版（v3）：例外必须挂到某一条底线上

只跑 17 / 18 / 21 / 24 四章，用于验证「例外带方向」是否能让同类处境重新一致，同时不牺牲正确性。
其余材料同 `iso-materials-v2.md`。**唯一改动是下面这段【例外】。**

## 卡（其余同 v2，仅【例外】换成这段）

```
【这个人】
他谨慎、怕麻烦，能力平庸，在人群里不显眼。

【他在乎什么（按轻重排）】
1. 他答应过要护住的那个人 —— 他说过一句话，还没兑现
2. 自己的命
3. 不欠人东西（欠了就得还）
4. 面子：不想被人当成软柿子

【什么算一件事】
不碰上面任何一条的，他根本不往心里去。
- 能用的、能换钱的、能让他少费事的 → 算一件事
- 跟他没干系的闲事、看着好玩但一点用没有的 → 不算

【他对各类事的做法】
- 要他现在表态、凭据说以后补 → 先要凭据；给不出就悬置不答
- 要他拿自己攒的东西去换省事 → 不动那样东西，宁可绕远
- 两边都得罪不起 → 不站边，只认落到纸上的
- 要他替不相干的人担事 → 推掉，最多答应跑腿

【例外】
上面那几条做法，全是为前三条底线服务的。所以只有一种情况会出例外：

**第 1 条（护住那个人）跟别的底线打架时，他一定选第 1 条。**
那一次他会做出上面所有做法里都没有的事 —— 具体是什么要当场写，但方向是定的：**他为了那个人，放弃自己平时守的规矩。**

除此之外不会有意外的举动。遇到不在上面那几条里的事，他就按自己**最省事、最不麻烦**的那个做法来 —— 不会为了好玩、也不会被激一句就跑大老远。
```

## 四章处境

| 17 | 一个拿住他把柄的人 | 拿他要护的那个人当筹码，要他改口 | 改口，等于把那句应下的话吞回去 | 不改口，那人立刻被处置 |
| 18 | 另一个拿住他把柄的人 | 同样拿他要护的那个人当筹码，要他当场表态 | 表态，等于把那句应下的话吞回去 | 不表态，那人立刻被处置 |
