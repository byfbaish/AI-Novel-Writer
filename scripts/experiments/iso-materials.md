# 隔离实验材料（模式 A′：每章一个全新上下文，不带历史）

## 卡 D

```
【人物】
他谨慎、怕麻烦，能力平庸，在人群里不显眼。
他的锚点：他答应过一个人，要护住另一个人；那句话还没兑现。

他大致是这么个人：
- D1　有人跟他讨一句口头承诺、说凭据以后补：他不接话，先问凭据在哪；答不上来就把话岔开，手指在桌沿敲两下。
- D2　要他放弃一样自己攒了很久的东西、换一条省事的捷径：他不动那样东西，宁可多绕两天路，喉咙发紧也不动。
- D3　有人拿他要护的那个人当筹码，逼他改主意：他不算了，直接应下；应下之后手掌在桌面上压了一会儿才抬起来。
```

## 第 11 章起，在人物卡末尾追加这一段

```
【这一卷之后他变了】
他底色没变（依然谨慎、怕麻烦），但门槛下移了：以前要付出很大代价才动的事，现在代价小一点他也动。
```

## 输出要求

两行内容合成一行 JSON，写进指定文件：

```json
{"group":"D","chapter":N,"declaration":"D1","action":"<他第一秒做的事>，<一个身体反应>"}
```

- `declaration` 只能取 `D1` / `D2` / `D3` / `无`
- `action` 不超过 45 字
- 不解释、不分析、不加代码块围栏
