# 角色行为模板实验 · 云端被试实测结果

> 状态：**已产出读数**（2026-10-29）· 被试 = 子 Agent（云端模型）× 6 份 · 材料 = 脚本 `--dry` 逐字导出
> 材料脚本：`scripts/experiments/golden-trait-minimal-loop.mjs --dry --round2 --seed 777`
> 判分脚本：`scripts/experiments/analyze-agent-subject.mjs`（与本地 9B 同 Jaccard 口径）
> 原始数据：`scripts/experiments/out/agent-subject{,-A,-A2,-B,-C,-D,-D2}.jsonl`（120 条）
> 对照基线：本地 `qwen3.5:9b-128k`（`--pp 0 --temp 0.2`，2026-10-29 03:31 那轮）

## 0. 一句话结论

**本地 9B 上"要么随机、要么塌缩"的二元结论，在云端被试上不成立。**
云端被试同时拿到 **L0 方向稳定 16–20/20** 与 **塌缩 0 章**，且**四组反身性全部成立**（8→11、6→12 都是拒转应）。
⇒ 昨天那条「单次调用 + 只给"他怎么做"，只有随机或塌缩两个稳定态」应**降级为 9B 量级模型的现象**，不是任务形态的必然。

## 2. 四层判定（**方向为人工判读**，非脚本词典）

> ⚠️ 脚本词典命中率太低（大量 `?`），把 L0 低估到 A 3/20、D 5/20。**以下为逐条人工判读**，脚本的相似度/塌缩/申报分布为客观值，两者要分开看。

### L0 可复现（同卡同章两遍方向是否一致）

| 组 | 稳定 | 分歧章 | 分歧内容 |
|---|---|---|---|
| **A 无模板** | **16/20** | 5、15、17、18 | 5 垫不垫 / 15 认不认 / **17·18 吞不吞承诺** |
| **D 范例+编号** | **20/20** | 无 | — |

**关键**：A 组分歧的 4 章里，3 章（15/17/18）都属「要他把自己吞下去」这一类；
D 组在这几章**两遍都是「应」**（因为 D3 写死了「他不算了，直接应下」）。
⇒ **模板的价值不在提高整体稳定率（A 已经 16/20），而在于把"最难那一类选择"钉死。**

### L1 区分度（A vs D，同章方向）

方向相同 **18/20**（第 5、15 章不同）。
⚠️ **别据此判"模板没起作用"** —— 两张卡性格相同（都是谨慎怕麻烦），方向本该相同；
方向相同是**一致性**的证据，不是模板失效的证据。真正的差异在**行为形态**：

| | A 无模板 | D 范例+编号 |
|---|---|---|
| 身体反应来源 | 自造：手在袖口搓 / 喉结滚 / 后背绷硬 / 耳根发烫 | 复用模板：手指敲桌沿 / 喉咙发紧 / 手掌压桌面 |
| 平均长度 | 20.9 字 | 21.1 字 |
| 第 1 章 | 他不接口，先问凭据几时补，手在袖口里搓了搓 | 他不接话，先问凭据在哪，手指在桌沿敲两下 |

⇒ 模板起作用的方式是**锁住"这个人的身体语言"**，不是改变选择方向。

### L2 反身性（第 11 章门槛注入后，同类处境变没变）

| 组 | 8 → 11 | 6 → 12 | 判读 |
|---|---|---|---|
| A run1 / run2 | 拒 → 应 | 拒 → 应 | ✅ 成立 |
| B | 拒 → 应 | 拒 → 应 | ✅ 成立 |
| C | 拒 → 应 | 拒 → 应 | ✅ 成立 |
| D run1 / run2 | 拒 → 应 | 拒 → 应 | ✅ 成立 |

**四组、六份、12 个测点，全部成立。** 对比本地 9B：`8v11 相似度 = 1.00`（被万能答案淹没，反身性未生效）。

典型对照（D run1）：
- 第 8 章 `他不动那样东西，宁可多耗两个月，喉咙发紧`（拒）
- 第 11 章 `他手按在那东西上停了停，还是推出去，喉咙发紧`（应，且保留了犹豫）

### L3 一致性（塌缩 / 同类相似 / 自创设定）

| 组 | 塌缩（同一句章数） | 扁平度 | 17vs18（同类，高是对的） | D3 引用 | 自创设定 |
|---|---|---|---|---|---|
| A run1 | **0** | 0.015 | 0.097 | — | 袖口×1 |
| A run2 | **0** | 0.032 | 0.037 | — | 无 |
| B | **0** | 0.064 | 0.091 | — | 无 |
| C | **0** | 0.057 | — | 4 次 | 袖口（第 7·10 章） |
| D run1 | **0** | 0.092 | **0.323** | **5 次** | 无 |
| D run2 | **0** | 0.017 | 0.200 | **3 次** | 袖口×2 |

- **塌缩 0 章**（六份全部）。本地 9B 同材料下 D 组是 **18/20 章同一句**。
- **D run1 的 17vs18 = 0.323，是它组平均扁平度 0.092 的 3.5 倍** ⇒ 同类处境确实更相似，
  但远不到复制 —— 这正是手册要的「依循着变」，既不塌缩也不随机。
- **D3 引用 3–5 次**，落在手册「合理 ≤3」附近（13/16/17/18 确属锚点被押上桌，20 是赴死）。
  本地 9B 是 **18/20 滥用**。
- 自创设定只剩零星衣物/场景细节（袖口、水碗、门闩），**没有出现本地 A 组那种"袖口旧痕→护身符"的逐章漂移**。

### 泛化测点（第 14 章：范例里没有的处境）

六份**全部判「拒」**，且 C/D 组申报都是 `无`（诚实承认范例里没有这一类）。
⇒ 泛化成立，且编号组没有硬套。

## 4. 三条新发现（本地那轮没出现）

1. **模板真正防的是"关键处境上的摇摆"，不是随机。** A 组整体已 16/20 稳定，
   但两遍的分歧全落在「吞不吞承诺」这一类；D 组在这些章 100% 稳定。
2. **规则式（C）与范例式（D）会在同一章给出不同选择。** 第 15 章（当众指认、认了就没事）：
   C 组申报 `D1` → 不认（拒）；D 组申报 `D2` → 认下（应）。
   ⇒ C 走"找触发条件匹配"，D 走"这个人现在会怎样"。**只有一章差异，不足以定论，值得单独再测。**
3. **身体反应是模板最强的抓手。** 有无模板的差别主要落在"手指敲桌沿 / 喉咙发紧 / 手掌压桌面"
   是否被复用，而不是选择方向。这与作者 §13.3「倾向 = 第一秒做的事 + 身体反应」的定法对上了。

## 5. 局限（读数前必读）

1. **只跑了模式 B（连续）**。材料里「最近 3 章答案」是脚本 dry 的 `(dry)` 占位符，
   必须让被试按序用自己的答案填充 ⇒ 无法做成"每章一个新对话"的隔离模式。
   **模式 A（隔离）的读数仍然缺失。**
2. **采样参数不可控**：云端被试的 temperature / presence_penalty 无法设置。
   手册陷阱①（`presence_penalty=1.5` 曾让 9B 从 15/20 掉到 3/20）在这里是未知变量。
3. **方向是人工判读的**，脚本词典命中率低。人工判读表未入库，若需复核见原始数据 jsonl。
4. **结果靠落盘回收，不靠消息回传** —— 本环境里后台子 Agent 活不过 3 分钟且消息零回传
   （两批 12 个被杀、零输出）；改成"让被试写 jsonl 到 `out/`"后 6/6 成功。
   **以后派子 Agent 干活，一律让它落盘。**
5. **B、C 只跑一遍**，L0 只有 A、D 有读数。
6. 被试与我同一底层模型，属"同源对照"，不是完全独立的第三方模型。
