## 关键结论（供后续直接引用）

1. **A-1.2：本项目不做 perplexity / token-rank。** 代码链 `logprobs` 0 命中、provider 白名单不透传、响应解析丢弃；Ollama 能返回但只覆盖生成 token，不能给已定稿正文打分。禁止代理量冒充（n-gram perplexity 只能标「代理」）。
2. **阶段 2.5：需要标定，k≠1；但根因不在「单位≠字数」。** 文档记录版 k=0.577（2550/2600/2500 vs 1578/1519/1319），现库版 k=0.869（1780/1650/1650）；主因是**产出达成率**（合同 2500→1500）。更深根因：`keyEventsText()` 丢弃 `estimatedUnits`（`src/shared/blueprint-key-events.ts:193-196`）⇒ 已开卡 `861ab163`。
3. **C5 地名蹭线：阈值维持 3 不动。** 第 3 章是同型反例（3 字「，陈砚」是人名+标点，悬念核同义落地）；建议方案 C（整体落在人名/地名时追加「疑似蹭线，请人判」，不改稿不阻断）；mask 地名单独无效；第 11 章口径应写「意象层未落地、事层已落地」。WorkBuddy 独立复算 22 组同向（20 组 3–8 字、ch11 蓝图 6/大纲 3）。
4. **A-1.4：11 章 × 4 征兆**（①8/3/0、②6/4/1、③4/7/0、④8/3/0）；ch10 四条全中最重；**11 章里 6 章同一「账目谈判」骨架** —— 解释过密是结构性的，不是全局文风。
5. **新旧正文对照**（n=2 只作方向）：ch6 旧 1578 字/117 句 vs 新 1330/86（连接词密度 1.2674→0.7519、对话占比 0.2706→0.1211）；ch10 旧 1520/105 vs 新 1298/89。caveat 全部写进报告：①恒 0、②下界、③含字面误命中、归因不清。
