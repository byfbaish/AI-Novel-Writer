# 规则台账（Rule Registry）

> 状态：已生效（2026-11-07）· 依据：`documentation-charter.md` §12「规则分档」· 全量盘点对象：`AGENTS.md`、工作记忆注入层、`docs/agents/` 各通道手册、`notes/` 各主题卷
> 用途：**每条规则只在这里登记一次**——它属哪档、落在哪、失败形态是什么、有没有闸门。加规则先查这里有没有同族；改规则先改这里的行。
> 读法：**不是给人背的**。它回答三个问题：这条规则还有效吗？它在哪个文件？它凭什么占用注意力？

---

## 1. 为什么要有这份台账（2026-11-07 的事故）

2026-11-07 上一窗口把「只做计划」做成了**计划未批先执行**：代码改了、状态行改了、文件提交意向已产生，作者回看时**已无法完整撤回**。事后核查发现：

- 当时**没有任何一条规则写「只让做计划时不许动代码」**——不是被忽略了，是从来没写过。
- 同时 40 余条规则**全部等重**（`★★` / `★` 混用，无档位），读者无法判断哪条该先看；注意力被平均分摊 ⇒ 关键的没被看见，冗长的被略读。
- 规则散落在 4 个文件、3 处互有重复（`AGENTS.md` 硬规则 6 与 §「要做什么→先读什么」表重复、裁定口径在 `AGENTS.md` 与注入层各写一遍）。

结论：**规则不缺，缺分级与唯一落点。** 本台账是这次重排的产物与凭据。

## 2. 分档判据（正文在 charter §12，此处只放速查）

| 档 | 准入（两条同时成立） | 判定问题 |
|---|---|---|
| **T0 不变量** | 后果**不可逆或静默** ＋ **每次会话都可能触发** | 违反了，作者当天能自己发现吗？能 ⇒ 不是 T0 |
| **T1 触发型** | 有明确触发条件，但不是每次会话都该占注意力 | 只在「加列 / 改模板 / 收口一期」才有机会 ⇒ T1 |
| **T2 判据型** | 要用它得先有判断力（边界、反例、为什么） | 删掉原因只留一句就执行不了 ⇒ T2 |
| **T3 证据型** | 一次复盘、一次交接 | — |

**两条附加**：**T0 必须配闸门**（脚本或强制读入点）；**T0 总数上限 8 条**，加第 9 条须先证明某条已不成立。

## 3. T0 不变量（8 条 · 唯一清单在 `AGENTS.md` §2）

| 编号 | 规则 | 失败形态 | 触发 | 闸门 |
|---|---|---|---|---|
| R01 | **授权边界**：开工先写一句 `本轮授权：<只读/只计划/可改码/可提交/可推送>`；**未明说 ⇒ 按最窄（只读）执行** | 不可逆（提交无法撤回、作者决策被绕过） | 每次会话 | ✅ **fail-closed 默认值**（charter §7 第 0 步） |
| R02 | **先讨论再落地**：规则 / 层级 / 契约 / 格式的改动先给方案等点头 | 返工（一次成型必偏） | 每次结构调整 | 🕳 无 |
| R03 | **不猜根因**：先取证再改；测试失败先 `stash` 对照 | 改错地方、掩盖真因 | 每次排查 | 部分（`stash` 对照） |
| R04 | **干完 ≠ 完成**：不自己宣布完成，交隔离上下文子 agent 审；签字换身份 | 静默（作者信了未验证的完成） | 每次交付 | ✅ 任务看板 `review` 拒同名 |
| R05 | **同提交同步文档**：改码那次提交里同步设计稿 / ADR / 台账 | 静默（文档漂移，下个会话按错前提开工） | 每次提交 | ✅ `pnpm check:fast`（pre-commit） |
| R06 | **提请裁定用产品语言**：讲流程 / 卡点 / 意图 / 后果，代码只作证据 | 不可逆（作者思路被拟合，一起进死胡同） | 每次要裁定 | 🕳 无 |
| R07 | **规划不是数学**：完本字数 × 单章字数是一等目标，章数是派生落点，只报偏差不拦截 | 方向漂移（工程目标偏移到卷数 / 章数） | 每次规划与收口 | 🕳 无 |
| R08 | **并行隔离**：worktree 只准单元测试（禁全量 / `test:browser` / `test:node`）；派出去的 agent 不给 `review` / `done` | 不可逆（切 ABI 打断所有槽位的 dev） | 每次并行 | 部分（`WORKTREE_SLOTS` 写死端口） |

> **闸门现状**：8 条 T0 里 **4 条有闸门**（R01 默认最窄 · R04 看板拒同名 · R05 `check:fast` · R08 部分）、**4 条待补**（R02 · R03 的一半 · R06 · R07）。失败形态都是「不可逆或静默」，却只靠"读过"——这是当前最薄的一处，缺口见 §6。
