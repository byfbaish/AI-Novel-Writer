# 验收门（Acceptance Gates）

> 2026-11-12 首版 · QA 维护。
> 一句话一条，每条必须能落到：**谁 · 在哪里 · 跑什么 · 看到什么算过**。
> 判据用「可观察证据」写，不用「已完成 / 已修复」这类形容词。
> 任一门的证据必须落盘（日志 / 报告 / run id / 截图路径），口头结论不采信。

## 0. 分级

| 级 | 频率 | 谁签 |
|---|---|---|
| **L0 卡门** | 每张卡 / 每次提交 | 执行者自检 + 换身份复核 |
| **L1 冲刺门** | 两周一个冲刺 | 总负责人 + QA 抽检 |
| **L2 期门** | 每期（1.3 发布前） | QA 出结论，总负责人签字 |

**基线口径（2026-11-12 修订）**：浏览器全量**不得多于 1 条红**，且剩余红必须是 B11（`RendererStartup.browser.tsx:137`）。
- 11-11 实测为 `2 failed / 835 passed / 837`（B11 + B16）。
- 11-12 报 `1 failed / 836 passed / 837`（总数不变）⇒ 消失的是 B16，与提交 `c073159f fix(d16,b16)` 吻合，属**基线下调**，不是漂移。
- 复跑若回到 2 条且第二条仍是 B16 ⇒ 判 `c073159f` 未生效，当轮不合格。
- Electron 运行时全量 `pnpm test` 基线由 11-12 夜跑首建，未出数前 L2 不得判过。

## L0 · 卡门

| # | 谁 | 在哪 | 跑什么 | 看到什么算过 |
|---|---|---|---|---|
| G1 | 执行者 | 自己的工作区 | `pnpm check:fast` | 三行 `✓`（typecheck / doc-links / doc-placement）且 exit 0；任一 ✗ 不提交 |
| G2 | 执行者 | 自己的工作区 | `pnpm test <改动路径>` | 输出 `N passed` / 0 failed，且 N 不小于该文件基线数；**新增红即失败** |
| G3 | 复核者（非执行者） | 看板 | 读卡 → 复跑判定线 → `release` | 执行者只到 `review`；执行者自己 `done` 的卡一律视为未交付 |
| G4 | 判读人 | `reports/` | 打开报告首段 | 首段能读到「结论 / 产物路径 / 判定线复跑命令」三项；缺任一项卡不算交付 |
| G5 | 派卡人 | 卡面命令 | 检查 `CODEBUDDY_SAFE_DELETE_ENABLED=0` 前缀 | 所有会写/删文件的卡必须带；缺此项的卡不许派（依据 11-12 P0：shim 缺变量即绕过 50 上限） |
| G6 | 判读人 | 卡面 | 对照卡面判定线 | 卡面必须预先写死「判定线 + 反例 + 产物路径」；缺一行不派，事后不补写 |

## L1 · 冲刺门

| # | 谁 | 在哪 | 跑什么 | 看到什么算过 |
|---|---|---|---|---|
| G7 | 总负责人 | develop | `pnpm test:browser` | `1 failed / 836 passed / 837`，失败项只有 B11（`RendererStartup.browser.tsx:137`）；第二条红或失败项不是 B11 即冲刺不合格 |
| G8 | 总负责人 | develop | `pnpm dev` + CDP 9222，按产品经理的场景清单走一遍 | 每步界面出现预期文案/状态；run id 或截图落盘到本轮报告 |
| G9 | 总负责人 | 打包目录 | 选对应旅程脚本，例：`node scripts/f05-u05-blueprint-draft-journey.mjs --package-dir=<win-unpacked> --package-source-sha=<sha> --exe-sha256=<hash> --asar-sha256=<hash>` | exit 0，且脚本自报的断言全过 |
| G10 | QA | 上轮报告 + 卡面 | 抽 2 张上一轮结论影响最大的卡，按卡面判定线复跑 | 复跑结论与上轮报告一致；不一致则上轮该卡结论作废并重开 |
| G11 | QA | 质量账本 | 汇总三数：红数趋势 / 实机复验率 / 未结算卡数 | 任一数字较上轮恶化 ⇒ 本轮不合格，下一冲刺不得开新功能 |

## 用法

- 派卡前：G6、G5 必须先过，否则卡不进夜跑。
- 卡交付时：G2、G4 由判读人核；G3 换身份。
- 冲刺出口：G7–G11 全过才算一个冲刺完成。
- 期出口：G12–G15 全过才可谈发布。
