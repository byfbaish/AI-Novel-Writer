# 弧光提示词 · 网页验证组装稿（v2.1）

> 用途：把下面两段直接粘到任意网页大模型里跑一次。**这不是文档定稿，是验证件。**
> 数据源：真实项目「如果我的能力是每天第一句谎言都会成真」（150 章 × 2500 字，都市（细分：都市/脑洞/轻喜剧）），字段取自 `.ai-novel/project.db` 的 `project_core`。
> 组装口径：`systemRole` + 渲染后的 `content` + `systemSuffix`（本模板无 taskGuidance；`requiredContextVariables` 全部被正文引用，故无追加块）。

## v2.1 为什么改（v2 网页验证的三个失败）

| 失败 | 现象（v2 实测输出） | 归因 | v2.1 改法 |
|---|---|---|---|
| **小弧只有一场戏** | 「早餐摊别问我到没到」：一个人、一个地点、一次追问就说完了 | 我把"回合"定义成了一次交手 —— 一次交手就是一场戏 = 一章 | 小弧升级为**战线**：同一目标 × 同一对手 × **换过两种办法** × 翻转。粒度判据只有一条：他有没有换过办法 |
| **中弧是空的** | 中弧只有"路从 7 条收到 5 条"，没有自己的内容 | 我只让中弧答数量，等于把它写成了记账行 | 中弧必须答**局面**：谁在向他要什么、双方怎么交手、结束时**逼法变了什么**（关心→标价→立卷→债务） |
| **"失去退路"变成永久惩罚** | 「落点少了"在早餐摊随便应付第一句"的路」——他明天照样能去早餐摊 | 记账压在小弧上，全书几十条战线就要几十张底牌，人没有那么多底牌，模型只能编假损失 | 底牌 = 可复用解法（五类）；失去必须说得出**为什么回不去**；**记账只在大弧**（1–3 张），中弧 0–1 张，小弧不记账 |
| 赌注抽象 | 「失去早餐摊这个低风险开口场」 | 抽象资源不算赌注 | 赌注必须具体到人 / 物 / 身份 / 关系 |

## 怎么用

1. 有 system / 角色设定入口的（Claude、GPT、Gemini、豆包、Kimi）：系统提示粘第一段，用户消息粘第二段。
2. 只有单输入框的：两段用空行连起来一起粘，效果基本一致。
3. 对照：项目里现有的 `plot_structure_plan`（7,189 字符）是 v1 产出；v2 的产出在上面那张表里已被引用。

## 一、系统提示

```text
你是一位擅长长篇叙事结构的策划。你只负责切段，不负责写情节。

你输出的弧光是三层嵌套（大弧 ⊃ 中弧 ⊃ 小弧）；每一层只回答三件事：这一段切几块、这一段里谁在向他要什么、最后谁少了一条退路。

你不写具体事件、不安排章节、不判断哪一场戏好看——那是下一步（情节大纲）的事。你写得越细，后面的层就越没有可写的：一场戏只能用一章兑现，一条战线才撑得起三到五章。
```

## 一句话前提（Logline）
当录音棚杂工程实发现自己每天开口的第一句谎话必在24小时内成真，他必须在黑市、庄家与观察科的围猎中守住当天唯一一次不可撤回的额度，否则一句早安就能炸掉整条老街。

## 核心冲突链
程实把日子压到最小：少说话、不接电话、靠打杂糊口，可他的身份信息已经被挂上黑市，开口就等于出货。触发点是某天他刚醒时一句敷衍的"我马上到"，让房东的门牌和整条巷子的记忆集体错位，观察科第一次把他写进报告；从此庄家要买他的第一句、自媒体要拍他的第一句、观察科要归档他的每一次漏洞。他的主线目标是销掉档案、攒够租一间没人敲门的房子，最终把这句话的所有权收回自己手里。显性阻碍是三方势力轮流逼他开口；深层危机是他越想躲，代价越落在替他扛的人账上。

## 金手指定位
无获取过程，规则自他成年的某个清晨起生效。核心机制是被动触发、不可选择、不可撤回：只有他"说出口且自己明知是假"的话才算，写下来、发出去、梦话都不算；成真永远走最省事、最符合现有社会规则的路径，旁人不觉异常，只留下细节对不上的漏洞；一天仅一次，第一句被当面揭穿或第二句抢位，现实就会打架。进阶路线从"用废话和沉默拖住第一句"，到"以最小代价说谎"，再到"主动制造细节矛盾引导成真偏向少伤人的一侧"，但三条铁律永不解除，每次引导都要付出更高代价。

## 悬念骨架
显性冲突线：程实能不能撑到零点——今天的额度还没用掉，庄家的电话、自媒体的镜头、观察科的跟踪却已经堵在门口。隐藏主线：异常言论观察科为何只登记不定性，谁在系统性地收集"漏洞"；以及程实逐渐发现，自己并非第一个能被这样使用的人，上一位额度持有者的档案，就压在他那份卷宗的下面。

### 1.【核心规则与体系漏洞】

这个世界真正运转的底层不是法律，也不是钱，而是"现实补全机制"：它接受一条明知为假的口头陈述作为改写指令，一天一次，一次一人，改写方式由它自己挑。它没有说明书——因为触发条件长在程实脑子里，谁也验不了。

**判定源独占：全世界只有一个证人，就是他自己。**
"明知是假"无法被外部仪器、旁证或复述验证。由此长出三条硬后果：
- 观察科永远无法举证，只能靠"对不上的细节"倒推，他们本质是考古队，不是警察；
- 庄家买不到确定性，只能买"内容"——他们指定句子，赌它成真，输了认栽；
- 程实是全世界唯一能在最后一秒改口的人。没出口就不生效，改口不算撤回。他的一秒钟比一整条江的资产都值钱。

**成真路径的四条偏好（程实拿血换来的规律，可操作，但不可控）：**
1. **现成优先**：已存在或半存在的文书、排班表、系统数据 > 他人可顺势接受的记忆与说法 > 实物改动 > 无中生有。凭空造物最贵，所以几乎不发生——谎话总落在"本来就有人这么干过"的地方。
2. **就近优先**：改写落在物理距离和关系距离最近的人身上。所以永远先炸老城巷子，再轮到江对岸。这是主角住在哪里、哪里就倒霉的原因，不是运气。
3. **责任外推**：现实倾向于把改动安到一个已有责任人头上——房东、老板、排班员、系统管理员、前台。所以事后永远有人"看起来"该背锅。
4. **零成本绕行**：只要存在一条现成的合法路径，哪怕绕得荒唐，现实也一定走那条。程实后期能做的全部"引导"，本质是提前把某条路修到只剩一半，让谎话只能顺着走——每修一条，留三处可查痕迹。

**漏洞的物证形态（这是唯一的硬通货）：** 门牌号、排班表、监控时间戳、快递面单、户籍回执、群聊时间线。观察科以"三处细节互斥"为立卷门槛，达标即归档，归档即"重点观察"。门槛为什么恰好是三处，没人说得出。

**现实打架的触发条件（三条齐备才打）：** 当着程实的面 + 明确指出这句话是假的 + 这句话尚未落地或正在落地。任一条件缺一，成真照走。第二句抢位同理。打架不撤回已完成的事，只在原地翻开一个"说不清"的口子：路灯集体闪烁、监控丢帧、整条街的记忆互相矛盾。口子一定会有人来收，而收口子的人不会是好心。

**非对称优势，只有四条，且都带钩：**
- **判定权**：他一个人知道额度几时被消耗，别人只能猜。
- **记事本特权**：写下来的不算数。全世界只有他拥有一种无后果的表达方式。这本磨边记事本是他唯一敢说真话的地方，也是最值钱的情报源——它一旦丢，他就等于裸奔。
- **沉默定价权**：额度只在说出口后才消耗，所以"不开口"本身是资产，撑到零点就是白赚一天。
- **先铺路**：让现实无路可绕，只能走他修的那条。

三条铁律（一天一次、不可撤回、必须自己明知是假）永久有效，无解，只能绕。

### 2.【阶层断层与资源战场】

**不可调和的断层有三组，每一组都能直接开战：**

**江这边 / 江那边。** 老城区靠记忆活着——口头承诺、街坊记性、房东一句话；新城区靠记录活着——合同、征信、数据、房产证。谎言成真优先篡改的正是记忆和文书，所以老城的记忆是消耗品，新城的数据是硬资产。老城人自己都说"咱这片记性差"，没人知道为什么。江对岸那份"旧城改造规划"，本质上是在老城的记忆上做资产重估。

**定性方 / 被定性方。** 观察科的KPI是"把事件定性为集体错觉"，程实的目标是"别进档案"。两边目标结构性对立、无法妥协：要结案，就必须有人被写进报告；而只要不是程实，就一定是别人。这是全书最痛的一根刺——他每躲一次，报告里就多一个替他挨的人。

**买内容 / 卖时间。** 庄家要买他"说什么"，程实想卖的其实只有"什么时候说"。双方议价标的从一开始就是错位的，谁都觉得自己吃亏。

**核心稀缺资源，按价钱从高到低排：**

第一序列——**干净的一天**。一天不接电话、不见人、不说错话。它不能买、不能换，只能靠有人替他挡在前面。黑市给它报过价：一个干净的一天，成交价是一次额度的十倍。
第二序列——**第一句话的内容预订权**。不可转让、不可过户，只能预订：庄家先付定金，指定一句话，靠他照说不认账的君子协议。毁约的代价是黑市再把他的身份信息散一遍。
第三序列——**身份信息**（姓名+租址+作息表）。全市场唯一能真正买卖的东西，因为掌握它等于掌握"几点堵他门口"。目前市价：一份完整作息表，值老城一间房一个月租金。程实的作息表已经流出去过一版，他至今不知道是哪一版。
第四序列——**漏洞物证**。观察科要它立卷，庄家要它当把柄，自媒体要它做爆点。同一张排班表，三家人抢。

**主角的位置：** 最底层，同时是唯一货源。他既退不出市场（退场等于被围猎），也定不了价（资产不可验证，无抵押）。他能争的只有两样——时间差（今天谁堵在门口）和信息差（观察科记到第几条）。向观察科争销档，他没有筹码，只有配合；向黑市争"别再散我信息"，要用额度去换；向自媒体争"别拍"，只能靠撒谎自保，而撒谎正中对方下怀。他每一次"主动选择"，都只能在这四个字里挑：躲、拖、认、换。

### 3.【隐喻与深层危机】

**谁在隐瞒什么：**

观察科三个人常年干同一件事——把每起事件定性为集体错觉，绝不定性为"现实改写"。这不是他们懒，是规矩：报告一旦往上递，"现实可被口头修改"就会变成一份正式结论，那意味着全市的产权、户籍、合同、婚姻登记全部可以被追溯质疑。整座临海市的合法性，建立在"没人承认现实被改过"上面。所以系统只能归档，不能承认。而程实要销档，等于要求系统承认它无法承认的东西——他从一开始就在跟一堵不能开口的墙说话。

**压在他卷宗下面的那一页：**

他第一次被写进报告那天，会发现档案袋里纸厚得不对劲。袋子底下压着另一份卷宗，编号比他早，纸页发黄，结论栏是空的——上一位额度持有者的档案。观察科三个人里，有一个知道上一份是谁的，也知道那一页为什么没有结论。程实想销自己的档，就必须先翻开那一页;而那一页一旦翻开，最先被"重新定性"的，很可能是他自己。

**没人记得是谁定的门槛：**

"三处细节互斥"才立卷——这条内部惯例从哪来的？恰好是三处，不是两处，也不是四处。凑齐三处就能让一个人被重点观察，这是谁设计的筛子？有东西在系统性地收集漏洞，收集的时间比观察科的编制还长。

**江的来历：**

老城人常说"江对岸以前不是这样"，可所有地图、规划图、老照片都显示两岸格局至少三十年没变。那么反过来问：**如果这些记录本身，就是某一句谎话的产物呢？** 新城的每一栋地标、每一版旧城改造规划，是否都是历届额度一层层堆出来的结果？程实每天在江上来回，其实是在两种"已成真的谎"之间穿行。他随口一句"我马上到"，可能改的不是他,而是那扇门。

**禁忌的形状：**

老城人不给门牌纠错、不在江面上喊话、不说"这地方我记得不是这样"。这些不是迷信，是几十年事故后长在身上的肌肉记忆。没人记得原因，但每个人都照做——包括程实的房东。

**交汇点：** 程实的额度从他成年的某个清晨开始生效。那个日期，在观察科的某份旧卷宗里出现过一次。

■ 钩子
每约 800 字一个推进或钩子；前 300 字内立张力。
章末钩子必须是具体型（揭示／行动／威胁／疑问），类型必须轮换，不能连续三章同一类型。禁状态描述型钩子。
每章第一句必须是动作、对话或异常现象，不能是环境描写或状态描述。

【适用：正文】
■ 段落与对话
手机端每段 3–4 行（叙述段 40–120 字，对白段豁免），单段不超过 120 字。对话占比 25%–40%。单人场景豁免对话占比要求。打散均匀长短句，杜绝连续同结构句式与排比。主叙述句 7–15 字，描写句 15–25 字，多用短句独立成段。
■ 基础基调
维持 pulp 爽文基调：口语直白，压迫感强。
少比喻、少通感、少拟人、少意象堆砌，修辞预算留给伏笔与钩子。
叙述贴着主角主观感官走，把冷硬客观叙述换成人物体感视角。
角色情绪外露（恐惧、愤怒、紧张要写出来），但叙述语气克制（不煽情、不升华、不点题）。
恐惧与紧张靠生理反应呈现（僵、麻、发凉、指尖收紧、手抖、出汗），不写心理告白。
■ 对话
对话只承载推进剧情的信息与人物的声线差异，不写成说明文。
■ 留白与规则呈现
氛围细节允许留白，刻意不解释。
■ 真人叙事·最高优先级
拒绝工整闭环，禁止每段都「环境→动作→心理→总结」；允许叙事跳跃与省略，但因果链不能跳。读者可以不知道「他怎么知道的」，但不能不知道「他为什么这么做」。
紧张场景先写生理反应，再补环境，不先铺白景再写人。
删除说明式、总结式、解释式旁白。发生即发生，不解释原因、不帮读者复盘。
保留人类微瑕疵：允许轻微不完美语序、短句骤停、思绪断点。
能用动作体现心理就绝不直说；禁止「他意识到／他确认／他发现／他判断」。



【第 0 步：只定个数（这是本步骤唯一要算的东西）】
篇幅只回答一个问题：这段故事该切成几段。它不用来安排每段写多少。
- 大弧数 = 总章数 ÷ 100（下限 3，上限 12）
- 每个大弧的中弧数（2–6 个）：按这一段里到底有几个独立的对峙局面定
- 每个中弧的小弧数（2–4 个）：按这一段里到底有几条战线定（一条战线 = 同一目标上跟同一个对手反复交手，直到一方改策略）
★ 从【弧光个数】这一行往下，不许再出现任何章数、字数、篇幅分配。不写「约 N 章」，不算 Σ，不估"这一卷跨多少章"，不做差额校核。章号区间由系统按个数自动均分，不需要你算。
★ 个数的分布由内容定：同一层的兄弟弧不许个数完全相同（全给 3 个 = 没算过，只是套了个数字）。差 1 个是正常的。

【第 1 步：三层各自只答什么】
- 大弧（第一层）：一段世界和他都换了状态的时期。答五样：入口处境 → 落点处境；这一段收窄的是哪一类底牌；这一段换的阻力是谁；这一段结束时少了哪几条底牌、为什么回不去；时间密度。
- 中弧（第二层）：一段对峙局面。答两样：谁在向他要什么、双方各自用什么方式交手；这一段结束时，交手的**方式**变了什么。
- 小弧（第三层）：一条战线。答四样：他要什么；对手要什么、用什么逼他；他先试过什么、再试过什么（两种必须不同）；这一步的结果与翻转。

★★ 粒度判据（本步骤最容易错的一条）：把一个小弧讲给没读过的人听，如果"一个人、一个地点、一次追问"就说完了，那它是**一场戏**，不是战线。
  一场戏约一章；一条战线约三到五章。唯一的判据是：**他有没有换过办法**。
  没换过办法 = 他一直被动应付同一招 = 只有一场戏的量；换过两次办法、两次都栽在不同的地方，才有三到五章。
  同理，小弧的名字要写**争的是什么**（"早餐摊的那句「到了」"），不写一场戏的动作（"早餐摊别问我到没到"）。

★★ 中弧不能只写数字。只写"路从 7 条收到 5 条"不是内容，是记账；读者感觉不到，大纲也拿不到东西。
  中弧必须写得出一段**局面**：谁在向他要什么（对方的目标，不是"挡他的道具"）、他靠什么拖、对方靠什么逼；
  以及这一段结束时**逼法变了什么**——从关心变成标价、从标价变成立卷、从立卷变成债务。
  逼法变了，下一段才有入口；只是少了两个数字，就没有下一段。

【第 2 步：底牌怎么算（这是"退路"的唯一算法）】
底牌 = 一种**可以反复用**的解法，只有五类：谁肯替他说话（关系）、他还是谁（身份）、他能去的地方（场所）、他手上的东西（资源）、他能钻的空子（规则漏洞）。
★ 一次战术失败**不是**少了一张底牌：今天被问住了，明天还能再来。写"少了在早餐摊随便应付第一句的路"是假损失——他明天照样能去早餐摊。
★ 一张底牌算"失去"，必须说得出**为什么回不去**，只有五种理由：被登记了 / 被人知道了 / 人情用掉了 / 场所封了 / 身份改了。
★ **记账只在大弧**：一个大弧结束时，少掉 1–3 张，并列明是哪几张、凭什么回不去。中弧最多写 1 张（也可以 0 张：这一段是"守住了，但代价落在别处"）。小弧不记账。
  理由：全书几十条战线，一个人没有几十张底牌。逼每条战线都扣一张，模型只能编假损失。

【第 3 步：张力从哪来（不来自事件数量，也不来自事故大小）】
- 每段都要有**翻转**：他以为会怎样、实际怎样。写不出翻转，这一段就是"他做了一件事，做成了 / 没做成"，那是流水账。
- 赌注必须具体到人 / 物 / 身份 / 关系。写"失去早餐摊这个低风险开口场"不算（抽象资源），写"失去庞大勇愿意替他挡人这份人情"才算。
- 对手必须有**自己的目标**，而且非要不可。写不出对手要什么，这一段就只是障碍物，没有张力；对手一改策略，这一段就结束了。
- 不要用加大事故来造张力（车祸、命案、绑架）：日常流会走形成事故流。

【第 4 步：每段写得出入口（只要可达，不要求必然）】
- 因果要求 B 由 A 必然推出；可达只要求能从 A 走到 B。弧与弧之间只需要可达。
- 每段必须写清入口：从上一段的哪个具体状态出发、靠什么走过去。写不出来的，不是缺因果，是这一段没有路 —— 删掉或挪位。
- 下层落点不许越出上层相邻节点之间：小弧的落点不出本中弧的入口与出口，中弧的落点不出本大弧的入口与出口。
- 大弧之间必须有接续理由：它就是上一段出口到本段入口之间的那条路。

【第 5 步：节奏只由个数决定】
- 兑现了一次"他得到 / 他失去"，读者才觉得有推进。兑现频率 = 章数 ÷ 小弧数，而章数由系统按个数折算 —— 所以你能控制节奏的唯一手段是小弧个数，不是往小弧里多写事件。
- 每个大弧写一句时间密度：本卷把读者压在多长的时间里，为什么。写量级 + 理由，不写天数；它是压缩选择，不是世界日历，不约束大纲。
- 全书不要只用一种时间单位：三卷都写"几天"，读者感觉不到时间在走。

【第 6 步：收尾（只对最后一个大弧做）】
最后一个大弧必须同时成立三条：
1. 落点能正面回答【全书问题】（是 / 否 / 把问题重新定义），不能停在"他好像想通了""他终于明白了一些事"。
2. 落点里有一条是主角自己付的、拿不回来的代价（退路被封 / 身份变了 / 某段关系断了 / 他一直护着的东西没了）。只有配角付代价，不算。
3. 不开新线：不出现新的施压方、新的谜团、"后面还有事"的暗示。

## 三、跑完看这五条（可判，不靠感觉）

1. **小弧有没有换办法**：每条小弧能看出"先试 A、再试 B"；只有一招的，是场戏。
2. **小弧名字是"争的东西"还是"一场戏的动作"**：前者如「早餐摊的那句到了」，后者如「早餐摊别问我到没到」。
3. **中弧有没有局面**：说得出"谁在向他要什么 / 谁靠什么逼 / 结束时逼法变成什么"；只有数字变化的算失败。
4. **底牌账在不在大弧**：小弧里出现"少了…的路"就是记账错层；大弧里没写"为什么回不去"就是假损失。
5. **能不能摊开**：任取一条战线，能不能排出 3 章、每章都是同一场拉锯里的一次新交手？排不出 ⇒ 办法没给够。
