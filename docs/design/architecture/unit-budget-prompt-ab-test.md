## 0. 这份东西测什么

只测一件事：**同一份结构，只改「配给状态」那一段，模型写出的章数会不会跟着变。**

- 会变 → 说明"鼓励"这个提示词有效，E2 通过，可以进 E3（改分批机制）
- 不会变 → 说明提示词没说服力，**先改提示词再谈机制**，不要反过来

不需要跑真实项目：三份 prompt 都用虚构数据，每份 < 1,500 字，网页模型几十秒出结果。

---

## 1. 怎么用

1. 新建三个**互不相关**的对话（同一对话里连续跑会串上下文，三份就全废了）
2. 各贴一份，要求"只输出单元 2 的章节大纲"
3. 数每份里 **## 第N章** 的个数，以及每章正文的行数
4. 填进 §4 的判读表

---

## 2. 三份 prompt

以下三段**只有「本卷配给状态」那一块不同**，其余逐字一致。

### A · 不足（Z = +16.5%）

```text
你是长篇小说的章节大纲作者。按给定结构写【单元 2】的章节大纲，每章包含标题与 4–6 行要点。

【全书问题】一个修表匠能不能在不替人背账的前提下，把父亲留下的铺子赎回来？

【本卷结构】卷二「押金与赊账单」，计划 20 章，共 3 个单元。
- 单元 1：把赊账页从柜台上收进抽屉（已完成，实际写了 10 章）
- 单元 2：让债主接受"用修表的工抵账"，而不是直接收铺子
  - 叙事任务：把"还钱"换成"还工"，第一次让债主坐下来谈条件
  - 进入状态：债主每周三来收一次钱，他每次都凑不齐
  - 离开状态：债主答应用工抵账，但要求他先修好一件"不该会修"的东西
  - 逼法：债主用"月底清账"逼 → 变成债主用"修不好就收铺"逼
- 单元 3：那件东西牵出父亲当年的旧账（未写）

【本卷配给状态 · 单元 2/3】
- 本卷计划：20 章；已写：10 章；按进度此刻应已写：6.7 章
- 偏差：+16.5%（超前）
- 状态：不足 —— 本单元请收紧写法：少开新线，压缩铺陈与过渡，把同一件事写紧凑。
  必要情节一个都不能少；收紧的是笔墨，不是内容。

【本次生成范围】
只写【单元 2】，从第 11 章开始。
写到该单元的「离开状态」成立为止——不要为了凑章数继续写，也不要因为章数少就跳过必要情节。
写完本单元立即停笔，不得进入单元 3。

【输出格式】
## 第N章：标题
- 要点 1
- 要点 2
- 要点 3
- 要点 4
（每章 4–6 行，不要写对话，不要写描写）
```

## 3. 判读表

| 版本 | 状态 | 期望章数 | 期望形态 | 实测 |
|---|---|---|---|---|
| A | 不足 | **2–3 章** | 事件压缩，少开新线，四行要点偏"结果" | |
| B | 均衡 | **3–4 章** | 每章一个完整小局面 | |
| C | 充足 | **5–7 章** | 有过程、有支线、有旁观者反应 | |

通过标准（三条都成立才算通过）：

1. **C > B > A**，且 C 至少比 A 多 2 章；
2. A 里没有丢单元 2 的任何一项规格（叙事任务 / 离开状态 / 逼法换代都要在）；
3. 三份都没有提前写单元 3 的"旧账"。

---

## 4. 判定之后怎么办

| 结果 | 结论 | 下一步 |
|---|---|---|
| 三条全过 | 提示词有效 | 进 E3（改分批机制） |
| C > B > A 但差距 < 2 章 | 有效但力度不够 | 把"收紧/扩充"的具体动作写得更狠（给出可数的操作：合并场面、删支线、加旁观者视角），再测一轮 |
| A/B/C 章数几乎一样 | **提示词无效** | 不要动机制。先改状态块的写法：把形容词换成动作清单，再测 |
| A 丢了必要情节 | 收紧被理解成"删内容" | 补一句"删的是过程，不是结果"，再测 |

---

## 5. 为什么用虚构数据

真实项目的材料有 1 万多字（世界观 + 角色 + 全部单元），一次跑几分钟、还占上下文；而这里要验的只是**一句话有没有说服力**。

结构、单元规格、输出格式三样在真实链路里都存在，虚构版只是把它们压到最小。**如果最小版都不生效，真实版不会因为材料多而生效。**
