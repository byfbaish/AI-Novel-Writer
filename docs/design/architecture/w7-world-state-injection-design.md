## 0. 为什么必须做

世界状态的闭环是六步：

```
写前注入（读快照） → 写（模型） → 写后抽取 → 校验 → 回写 → 再注入
```

现状盘点：

| 环节 | 谁 | 状态 |
|---|---|---|
| 写前注入 | **W7** | ❌ **缺** |
| 写后抽取 | W6b（资源）/ W3（角色 `stateDelta`） | W3 有，W6b 待做 |
| 校验 | W3 审稿链 / W6b 账本算术 | 部分有 |
| 回写 | W3 定稿期交叉 → `cs_*` | ✅ 有 |
| 再注入 | W7 | ❌ **缺** |

**只有账本而没有注入，等于「事后能查出、写的时候照样不知道」** —— 模型在第 5 章仍然自己编一个余额，你只是在第 6 章才发现它编错了。这就是作者说的「不闭环没有意义」：**校验的价值上限由注入决定**。

## 1. 注入什么（最小集，不是全量）

| 状态项 | 来源 | 形态 | 缺失时的样子 |
|---|---|---|---|
| **资源余额** | W6b `resource-ledger` 推算到"最近一个可算章" | `灵石 20 枚（第 4 章结余）` | 账本中断 ⇒ `第 n 章起未知`；资源未登记 ⇒ **整节不出现**（不写 0） |

| **待生效承诺 / 期限** | 后置（W7c 再议） | — | — |

这四条里前两条是预算问题，后两条是**剧透问题** —— 见判据 **DP**。

## 2. 注入到哪：复用既有通路，不新开模板变量

现状事实（`generate-draft.command.ts:866-871`）：

```ts
// 这一格刻意留空：角色状态并进了作者材料块（readCharacterProfiles 的注释里写了原因
// —— 续写轮不带模板变量，只带材料块）。留空也让下面的「空段裁剪」照常生效。
.withCharacterStates('')
```

**这是一个必须沿用的约束**：正文链的续写轮**不带模板变量**，只带作者材料块。所以：

| 链 | 落点 |
|---|---|
| 正文生成 | **作者材料块**里新增一节「【当前世界状态】」（与角色状态同一块，续写轮也生效） |
| 审稿 | `withCharacterStates(frozen.characterStates)` 已存在；快照走同一份渲染函数 |
| 蓝图/大纲 | 本轮不动（它们看的是计划，不是状态） |

**一条硬约束**：`src/shared/character-state-lines.ts` 的先例 —— **同一个纯函数产出一份文本，两条链共用**。
绝不能正文一份渲染、审稿另一份渲染，否则两边对同一状态的表述会漂移（判据 **DM**）。

## 3. 切片：为什么现在就要定，而不是以后再说

作者原话：「只在当前卷内是创作空间和关注要素」。这不是显示层的过滤，而是**定义"什么是当前有效的世界状态"**。

**好消息：卷的权威边界已经存在，不用新建。**

| 需要的东西 | 现成的在哪 |
|---|---|
| 卷边界（第几卷、第几章到第几章） | `src/shared/arc-position.ts`：`volumeIndex` / `volumeStart` / `volumeChapters`（`naming: 'volume'` 时标题写「卷」，否则是旧「大弧/中弧」） |
| 三层投影的形态 | `volume-quota-context-budget-design.md` §0：**本卷全文 + 上一卷快照 + 最近 K 章** |
| 卷末快照的语义 | 同稿 §5.4：只记"要交给下一卷的"，**生命周期终止于下一卷** |

**所以 W7 的切片规则直接沿用这三个，不发明新概念**：

```
注入的世界状态 = 本卷内状态（全量）
               + 上一卷快照（一份，仅结转项）
               + 最近 K 章的状态变化（K 待定，建议 3）
```

**为什么现在就要定**（这正好呼应「打地基」）：

1. **不切片的注入在长篇上必然爆** —— 与 E4 同一个算术：状态条目数随章数线性增长，而资源账本每章至少一行；
2. **事后再补切片要动所有快照生产者** —— 每个产出状态的地方都要重新回答「这条属于哪一卷」，改动面远大于现在定一条规则；
3. **M11 建表时不需要额外预留**：`resource_movements` 已有 `chapter_number`，卷可由章节→卷映射推导（映射的权威在弧光，不在状态层）。**但卷末快照需要一个落点**（W7d / E4 的 T11），现在不建表，只确认它不与 `resources` / `resource_movements` 冲突。

## 4. 缺失与陈旧的显式降级

沿用判据 CS/DJ 的口径，**取不到就说不确定，不填 0**：

| 情况 | 注入文本 |
|---|---|
| 账本在第 n 章中断 | `灵石：第 4 章结余 20 枚；第 5 章起无法推算（该章未抽取变动）` |
| 资源从未登记 | 整节不出现（**不是** `灵石 0 枚`） |
| 角色六槽全空 | 该角色只出现名字与「未观测」 |
| 日序未知 | 不写「第 X 日」，不写「第 0 日」 |
| 状态快照比本章旧（例如读完第 14 章生成第 16 章） | 明确写 `截至第 14 章`，不假装是最新 |

**为什么这么啰嗦**：模型看到「20 枚」会当成权威；看到「20 枚（截至第 4 章）」才知道需要自己判断这中间有没有变化。**省略限定语 = 制造新的错误源**。

## 5. 预算与裁剪顺序

复用 E4 已有的字符/字节闸门，**不新增第二个预算体系**。超预算时的裁剪顺序（从先裁到后裁）：

1. 远期连续性事实（与本章角色/资源无关的）
2. 次要角色（本章蓝图未点名的）
3. 历史章的状态观测（最近 K 章之外的）
4. —— **资源余额与主角六槽永不裁**（裁了就等于没注入）

## 6. 判据（接在 W6 的 DI–DL 之后）

| 编号 | 判据 | 违反症状 |
|---|---|---|
| **DM** | **注入与校验同源**：注入的快照与审稿/账本读的是同一份数据、同一个渲染函数 | 模型按 A 版本写、校验按 B 版本判 ⇒ 每章都在"修"一个不存在的错误 |
| **DN** | **未知不得填 0**（CS 同型）：账本中断、资源未登记、日序未知都必须显式缺失 | 模型把「未知」当成「0 枚」写进正文，错误从此固化 |
| **DO** | **切片边界只有一个权威**：卷边界来自弧光结构，状态层不另存一份 | 两份卷边界漂移 ⇒ 同一章在不同入口属于不同卷 |
| **DP** | **注入即划期界**：未来剧情、远期设定不得进快照 | 模型提前泄露反转（先例：`review-far-term-setting.ts` 的"告诉模型 + 划期界"姿态） |

## 9. 不做

- ❌ **全量世界状态注入**（那正是 E4 算过会爆 133k–200k tokens 的做法）
- ❌ 注入未来剧情 / 远期设定（判据 DP）
- ❌ 新建卷表或第二套卷边界（判据 DO）
- ❌ 改生成模型的调用结构、改模板变量契约（续写轮不带模板变量这条不能破）
- ❌ 自己做抽取或算术（那是 W6 的职责）
- ❌ 注入「谁知道什么」（等 C1 的身份分面）
