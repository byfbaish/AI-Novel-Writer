# 角色内核层：把「动机 / 禁区 / 恐惧」下沉到一条 Lie

> 状态：**已部分推翻**（2026-10-28 晚，作者裁定）→ 见 [`character-disposition-state-design.md`](character-disposition-state-design.md)
> **保留**：§2 三学科分层查证、§3「三条同源」诊断、§5 机制下限、§6 作用域分析。
> **推翻**：落点。作者裁定「性格特征这一层就够」，且**性格要作为状态维护、按卷位移**——
> 所以机制建在「if–then 倾向 + 位移」上，不建在「恒定的 Lie + 硬禁区」上。
> 根因：**否决条件（二值）天生不可变**，做不出连续成长。
>
> 触发：作者问「动机、做不出什么、恐惧的根源来自性格特点或性格缺陷，机制能不能再底层一点」
> 前置：[`choice-source-and-elimination-design.md`](choice-source-and-elimination-design.md)（选择行改力源 + 淘汰，已落地）

## 1. 问题

上一轮把选择行改成了「力源 + 否掉了…因为…他的哪一条」，并写死推理顺序：翻底（动机 / 做不出什么 / 最怕什么）→ 列三个够得着的 → 用禁区划掉 → 取第一个剩下的。

作者指出：这三条本身不是根，它们的根是**性格（或性格缺陷）**。

诊断成立，而且比"缺一个根"更严重：**这三条现在是三个独立字段，模型可以各编一条彼此不相干的清单**——动机写"变强"、禁区写"不杀无辜"、恐惧写"失去朋友"，三条背后没有同一个内核。结果读者读到的是"一个选项集合"，不是"一个人"。

## 2. 行业里「性格」本来就是分层的，我们现在停在最上面那层

三套互不相干的学科，指向同一个层级结构。

### 2.1 人格心理学：McAdams 三层（McAdams 1995；McAdams & Pals 2006）

| 层 | 行业名 | 内容 | 关键性质 |
|---|---|---|---|
| L1 | dispositional traits（特质层） | 大五：神经质 / 外向 / 开放 / 宜人 / 尽责 | **去情境化**（decontextualized）、最稳定、生物基础最强 |
| L2 | characteristic adaptations（特征性适应层） | 动机、目标、价值观、应对策略、图式、自我意象 | **带情境**（"在特定时间、地点、社会角色中表达"） |
| L3 | integrative life narrative（整合人生叙事） | 他讲给自己听的"我是谁" | 把 L2 组织成一条连贯的线 |

原文对 L1 的描述是 "broad, decontextualized manifest tendencies"——**去情境化**这个词是判据：它描述的是跨情境的平均倾向，因此**恰恰预测不了"这一章他会怎么选"**。

我们现有资产落在 **L2**（`motivation` 核心动机、`personality` 性格特征、"灵魂软肋"）。L2 本身是被 L3 组织起来的，我们缺的是那根组织它的线。

### 2.2 临床认知：Beck 信念层级

| 层 | 内容 | 形式 |
|---|---|---|
| core belief（核心信念） | 对自我 / 他人 / 世界的**无条件、绝对、全局**判断 | "我不可爱" / "我无能" / "我没有价值" |
| intermediate belief（中间信念） | **条件规则**：态度、规则、假设 | `If I <做某动作>, then <我不会暴露核心信念>` |
| automatic thought（自动思维） | 情境触发的一闪念 | "他觉得我不行" |

关键在于**中间信念是把核心信念翻译成行为的那个齿轮**，而且它的标准形式是 **if–then 条件句**——这正是"做不出什么"的语法原型：

> 禁区 = `If I <接受施舍>, then <我就是那个欠着不还的人>` 的**反面强制**

### 2.3 叙事学：Weiland 弧光链

`Wound（伤口：具体一件过去的事）→ Lie（他信的一句无条件的话）→ Want / Need`

- **Wound**："the specific past event that made the character's Lie feel like truth"。没有它，Lie 就是**作者贴的标签**；有了它，Lie 是**他从实际经历里得出的合理结论**——所以极难放弃，放弃时才动人。
- **Lie** 是操作系统，不是装饰：它决定他如何解读每一个事件、每一段关系、每一次挫折。
- **Want vs Need**：Want 是 Lie 告诉他"你该要这个"；Need 是他真正缺的 Truth。两者必须冲突。

转述该书的一篇编剧指南给了一句判据（非原书原文，注意引用层级）：

> "If your character can get what they want and what they need at the same time, you don't have a character arc. You have a to-do list."

### 2.4 编剧骨结构：Egri 三维（《The Art of Dramatic Writing》）

`Physiology / Sociology / Psychology`，且 **Psychology 是前两者的产物**（"the most complex of the three is Psychology, and is the product of the other two"）。

用途不是生成，是**校验**：Lie 能不能追到他的社会处境。追不到 = 作者贴的标签。

## 3. 诊断：三条是同一个内核的三个投影

这是本轮的核心结论。

给定一条 Lie，三条是**机械可推**的：

| 现有字段 | 本质 |
|---|---|
| 动机 | 他以为能**证明**这条 Lie 为真的那件事 |
| 禁区（做不出什么） | 一旦做了就会**证伪**这条 Lie 的那些动作 |
| 恐惧 | 这条 Lie 被**当众证伪**的那个场面 |

也就是说：**禁区是保护 Lie 不被证伪的行为，恐惧是 Lie 被证伪的场面，动机是能证明 Lie 为真的目标**——同一件事的三个面向。

这正是 Beck 中间信念的定义式 `if I <做某动作>, then <我不会暴露核心信念>` 反过来读：**禁区就是那个 if 不许他做的动作**。

### 3.1 一个具体的例子

```
内核：他爹替人担保欠了三十两，债主上门那天，全村没有一个人开口 →
      「欠了人的，这辈子就抬不起头」
  ↳ 动机：把每一笔债都清掉（不是"变强"，是"清账"）
  ↳ 禁区：不接受任何人白给的东西，宁可饿死
  ↳ 恐惧：被人当众说"这家人还欠着"
```

三条全部可追回内核。反过来说，如果三条里任意一条追不回内核，**那就是模型编的**。

## 4. 机制

### 4.1 字段形态

角色卡里只要求一格，其余由它派生：

```
内核：<伤口：具体一件事、什么时候、他从中得出了什么> → <一句他会真的说出口的话>
```

三条派生要求（写进模板，不单独存自由文本）：

- 动机：**不是**通用欲望（变强 / 活下去 / 保护家人），而是"他以为能证明这句话为真的那件事"；
- 禁区：写**动作**，不写倾向；带"即使亏本也不做"；
- 恐惧：写**一个会被看见的场面**，不写情绪词。

### 4.2 三条判据

| # | 判据 | 出处 | 不过怎么办 |
|---|---|---|---|
| J1 | **闭包**：任意一条投影能否反推回内核 | 本文 §3（Beck if–then 的逆） | 推不出 ⇒ 是编的清单，重写 |
| J2 | **张力**：Want 和 Need 能不能同时满足 | Weiland | 能 ⇒ 这卷没有弧光，只有待办清单 |
| J3 | **可追**：Lie 能否追到他的社会处境 | Egri（psychology 是 physiology + sociology 的产物） | 追不到 ⇒ 作者贴的标签 |

J2 是可以直接变成条款的：**如果这一卷他能既拿到想要的东西、又变成该变成的人，这卷不算有弧光**。

### 4.3 Lie 的写法硬约束

- 必须是**他会真的说出口**的一句话，不是哲学抽象。「世界很残酷」是抽象；「先下手的人不会被抢」是 operational。
- 必须是**无条件句**。带"如果…就…"的是中间信念（禁区），不是核心信念。
- 只能有**一条**。两条以上等于没有——因为两条会互相给例外。

## 5. 机制的下限：能再下沉一层，但不能无限下沉

作者问"能不能再底层"——能，但**只有一层，且下限明确**。

| 层 | 内容 | 本系统里的位置 | 用途 |
|---|---|---|---|
| L0 | 生理 + 社会处境（出身、身体、时代给他什么、缺什么） | 世界观 + 主角档案（**已有**） | **只做校验**（J3），不参与每次决策 |
| L1 | Wound → Lie | **本轮新增** | 派生三条，全书不变 |
| L2 | 动机 / 禁区 / 恐惧 | 由 L1 派生 | 每章决策依据 |
| L3 | 力源 + 否掉了什么 | 选择行（已落地） | 可判输出 |

**再往下（大五特质、遗传）不能进机制**，理由来自 McAdams 自己的定义：特质层是去情境化的，它描述跨情境平均倾向，**预测不了具体情境里的选择**。写进 prompt 只会变成模型手里的一个形容词，而且会和 Lie 打架（"他很谨慎"与"他宁可饿死也不受施舍"并存时，模型会随机挑一个）。

一句话：**往下走一步是设定（校验用），走两步就变成形容词（有害）。**

## 6. 与既有条款的关系（必须先想清，否则互相打架）

上一轮写死了「**不允许说这次情况特殊**」——禁区不能有例外。而弧光的定义恰恰是**禁区被破**。两者不是矛盾，是**作用域不同**：

| 作用域 | 规则 |
|---|---|
| 单章 / 单元内 | 禁区**没有例外**。任何"这次情况特殊"一律视为角色走形 |
| 卷末弧光点 / 全书高潮 | 破禁区是**唯一允许的例外**，且必须满足三件：① 前置压力已累积到无路可走（走 `破` 必须有前置：时间 / 资源 / 知识）；② 破了要付代价；③ 破完之后这条 Lie 有裂缝，不能复原 |

不写清这条，模型会把"弧光"当成"随便破例"的通行证——这正是负向弧（corruption arc）与"角色崩了"的分界线。

## 7. 这条链顺带解释了「憋屈」

| 形态 | 机制 |
|---|---|
| 爽 | 他按 Lie 的方式赢了（Lie 被"验证"） |
| 真爽 | 他被逼做了禁区里的事，而且赢了（Lie 第一次出现裂缝） |
| 燃 | 他做了禁区里的事，输了，但他没后悔 |
| **憋屈** | **Lie 一直有效、代价一直涨，却从来没被逼到要破** |

现在模型的默认行为正是最后一行：它不敢让他破禁区（怕角色走形），又不敢让他一直按 Lie 赢（怕没有变化），卡在中间就是憋屈。

**读者要看的不是"他能不能赢"，是"他会不会为了赢去做那件他一直做不出的事"。**

这一句也是上一轮那条判定句的根：「否掉了…因为…」里的理由，必须能追到内核，否则就是模型替他选的。

## 8. 落点与成本

### 甲：新增 `lie` / `wound` 两个字段

需要动：DB schema + 迁移、`character-store.ts`、`CharacterEditor.tsx`、`character-proposal-parser.ts` 的两处字段白名单（`:92`、`:280`）、`character-background-prompts.ts` 的 JSON 契约（中英）、`cast-ledger-completion.ts`、`character-roster-client.ts`，以及 UI 文案。

**成本高，且已存在项目要迁移。**

### 乙：不加字段，改写现有字段的写法要求（推荐）

| 字段 | 现在 | 改成 |
|---|---|---|
| `personality`（性格特征） | 偏好描述 | **内核：伤口 → 一句他会说出口的话** |
| `motivation`（核心动机） | "变强 / 复仇" | **从内核派生：他以为能证明它的事** |
| `arc`（角色弧光） | 起点 → 终点 | **这条内核什么时候碎、碎在哪一章** |

字段名一个不动 ⇒ **零迁移、零白名单改动、零 DB 改动**；只改模板措辞 + `CharacterEditor.tsx:398` 那一处 label。

符合上一轮的"单一变量"原则，也符合作者「不许出现第二份权威」的既有裁定：**内核只有一份，写在内核那一格，其余两格是它派生的说法，不是第二份定义。**

## 9. 不做的事

- **不加大五 / 特质维度**：去情境化，对情境决策无判别力，且会与内核打架。
- **不让角色卡自动重跑**：已存在的项目要作者手动触发一次架构链重生成，否则老卡没有内核格——这一点需要单独确认策略（沿用现有"已存在项目不自动重跑"的约定）。
- **不在本轮改弧光层**：J2 / J3 只是把内核接到弧光的接口，弧光本身的篇幅与分级不动（CE 两条红线仍有效）。
- **不做自动判据**：J1–J3 先作为模板自检项，等实机读数再决定是否上审计码。
