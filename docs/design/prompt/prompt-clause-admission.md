# 提示词条款准入三问（落笔前 gate）

> **状态**：已生效（2026-10-24，作者定）
> **上级稿**：[`industry-alignment-and-stage-goals.md`](../architecture/industry-alignment-and-stage-goals.md) §5（立项前四问）；本篇是**落笔前**准入，两者并列不合并
> **适用**：所有写进提示词模板的禁令式条款（`不要…` / `禁止…` / `必须…`），含生成侧与审稿侧

---

## 1. 总原则

> **禁令的对象只能是「无依据的写法」，不能是「写法」本身。**

AI 的毛病是「无铺垫的外援 / 无依据的碾压 / 无根的反转」；若写成「外援 / 碾压 / 反转」本身，就把作者明确要的合法写法一起禁了。

---

## 2. 三问

### ① 作者明确要求这种写法时，这条禁令还成立吗？

**判定口径**：假设章纲或作者指导里写着「本章引入强力外援」「要写碾压局」「插一段回忆杀」，这条禁令会不会与之打架？

**答不出来的后果**：不成立 ⇒ 它是偏好，不是规则，改写成带前提的（「不要**无铺垫的** X」）。

**追加口径**：前导行 / 优先级句不能代替这一步。模型对**具体禁令**的服从度高于抽象优先级，一条绝对禁令会反过来架空前导行 —— 2026-10-24 P14 就是这么失效的（条款写「不要让关键结果靠外力解决」，而作者可能在章纲里正当地要求外援）。

### ② 行业里有没有合法的反例？

**判定口径**：找公认成功作品里这么写且成功的例子。有 ⇒ 说明禁的是「依据」，不是「写法」。

**答不出来的后果**：找不到反例才允许用绝对禁令；找得到却仍写绝对禁令 ⇒ 必须进 §3 反例库并给出限定词。

### ③ 限定词够不够？

**判定口径**：这条禁令能不能指出**具体条件** —— 前文有没有埋过 / 与本章有无关系 / 数量 / 代价 / 时机？指不出 ⇒ 它是审美判断，不是规则。

**答不出来的后果**：不可判的条款对模型等于噪声，只占 token 不产生约束（实测见 [`2026-10-17-fanqie-draft-quality-evidence.md`](../../research/2026-10-17-fanqie-draft-quality-evidence.md) 第 180 行）。与判据 BD「判据必须是可算的区间，不是模糊的『够不够』」同型。

---

## 3. 反例库

| 别禁它 | 出处 / 例 | 为什么合法 | 该加的限定词 |
|---|---|---|---|
| 有铺垫的外援 / 救兵 | 甘道夫圣盔谷（说过「第五日黎明向东看」）；网文「祖师出关」 | earned miracle：早期建立可能性 + 最后一刻仍不确定 + 仍付代价 | 前文埋过 · 由本章人物召来 · 仍付代价 |
| 碾压 / 秒杀 | 爽文核心爽点 | 力量差本身是卖点 | 强弱与前文交代一致 · 写出力量差的根据 |
| 藏底牌式反转 | 扮猪吃虎 / 底牌流 | 网文最常用反转手法 | 底牌必须前文埋过（可藏，不可无中生有） |
| 收尾抛更大威胁 | 卷末钩子 | 追读机制 | 只提一句 · 不占本章笔墨 · 本章不处理 |
| 日常 / 种田 | 种田流、日常流 | 类型主体 | 日常本身构成进展（关系 / 信息 / 处境）才写 |
| 回忆杀 | 情感高潮章 | 情感兑现 | 必须与本章冲突或选择直接相关 |

以后改模板先查这张表，比重新争论「这样写对不对」快。

## 4. 与既有判据的分工

| 既有 | 管什么 | 与三问的关系 |
|---|---|---|
| **AV**（`.workbuddy/memory/notes/prompt-engineering.md:1311`） | 禁令的**形态**：必须配「那该写什么」的正面清单 + 自检问句 | AV 管怎么写；三问管**该不该存在** |
| **BA**（`.workbuddy/memory/2026-10-18.md:656`） | 同一批数字上只能有一条硬规则（两条硬规则会互相排除） | 三问第①问是它的前置体检 |
| **AP**（`.workbuddy/memory/2026-10-18.md:393`） | 给了上游权威必须同时给那一侧条款 | 与三问②同源：单边规定等于没规定 |
| **CR**（`.workbuddy/memory/notes/prompt-engineering.md:1550`） | 给审稿的规则必须是判据，不能是义务 | 三问产出生成侧条款；审稿侧的对应物归 CR |
| **BD**（`.workbuddy/memory/2026-10-18.md:703`） | 判据必须是可算的区间 | 三问③的直接依据 |

**本准则不新增判据编号**（2026-10-24 口径）；要表达约束就写「与判据 X 同型」并给理由。

## 5. 留痕（怎么证明过了准入）

新增或修改任何禁令式条款，必须在**对应设计稿的 §0.1「条款三问」表**里留答案：

| 条款 | ①作者要它时成立吗 | ②合法反例 | ③限定词 | 结论 |
|---|---|---|---|---|

不给 ⇒ 未过准入。第一个按此填表的是 [`p14-chapter-role-guidance-design.md`](p14-chapter-role-guidance-design.md)。

---

## 6. 为什么这份文档不是判据、不是红线

1. 判据编号已排到 DP，且最新口径是「不新增判据编号」；
2. 判据是**事后收据**（[`arc-layer-handoff.md`](../architecture/arc-layer-handoff.md) 第 159 行自己批评「几乎每一条都是某次补丁的收据」），三问是**事前工序**；
3. 判据 CJ 明令「不得出现应改为 X」，而三问的产出恰恰是「该怎么写」——写进判据会与 CJ 直接冲突。
