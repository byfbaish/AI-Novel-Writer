## 1. 先接受作者的三个判断

| 判断 | 为什么成立 |
|---|---|
| **性格必须作者定** | 这不只是审美问题，是**功能约束**：一个没有突破因子的胆小鬼，在那个世界活不过三章，当不了主角。模型随机出的性格有大概率是"活不下去"的那种 |
| **题库不负责"测"，只负责"译"** | 上一稿把题库当测量工具（无中生有地测出性格），方向错了。它真正的用途是：把"谨慎"这种抽象词，翻译成"遇到这种局面他会这么做"的**行为样例**，供模型照着推演 |
| **循环是真的** | 性格 → 选择 → 选择的后果 → 改塑性格。所以初始设定是"种子"，不是"结论"；种子必须由作者给 |

## 2. 查证：有魅力的主角，共性是三条刻度

英文编剧侧几乎已经形成共识（Scripta / Arc Studio / ScriptMag / bubblecow）：

| 要素 | 原文口径 | 我们的用法 |
|---|---|---|
| **主动性 Proactivity** | 「被动主角在戏剧上是惰性的」；主角必须**自己做选择**推动故事 | 对应"选择行"：每章必须是他做的决定 |
| **能力 Competence** | 关键不是强，是 **competence under constraint** —— 「在疲惫、破产、被围、害怕的时候还办成了，那才叫人物」 | 金手指之外，要有一条"他擅长的东西" |
| **可 relating 的弱点 Vulnerability** | 「脆弱要具体且克制」；「一页纸全是惨事 = wound parade，读者觉得被操纵」 | 底色里的缺陷，一条就够，不要说满 |

还有两条定论值得记住：
- **"别追着 likable 跑"**（bubblecow）：读者跟的是 **consistent / specific / active** 的角色，"为一个我们理解的理由做了可疑选择的人"比"飘过场景的圣人"更吸引人。
- **英雄必须至少有一个可被成长克服的性格缺陷**（ScriptMag）。

## 3. 查证：两类主角的"闪光点"到底是什么

### 苟道型（李长寿《我师兄实在太稳健了》）

一手材料是作者言归正传的访谈（封面新闻 / 辽沈晚报转载）：

- 「**仅有'稳健'这个特质，人物没办法支撑起一部 300 多万字的小说**」——必须不断"打补丁"丰富。
- 「**'苟'不是目的，而是手段**」；他特意写了句台词：暂时的苟，是为了拿到力量之后能护住更多人，而不是逞一时之气把自己牺牲在救人的路上。
- 「**所有的剧情都是为了贯彻'稳健'这个人设**」；而且「当作者赋予人物生命之后，就没办法完全干涉他所作的任何决定，**他会在自己的故事里作出符合人设的决定**」。
- 贯彻得越彻底，成长空间越窄：「导致描写人物成长性时受到了很大的限制……只能去抓他的人物弧光」。
- **全书最高点是反差**：「他稳到最后反而稳不住了，牺牲了自己去成全更多的人。」
- 读者粘性来自一个词：**安心**。「李长寿只要一出现，读者就会安心。」

⇒ **苟道主角的闪光点不是"苟"，是"苟是为了什么"，以及"什么时候他会不苟"。**

### 以力证道型（石昊《完美世界》/ 叶凡《遮天》/ 萧炎《斗破》）

- **石昊**：豪放不羁、行事果决、敢爱敢恨、重情重义，**且独断专行**（搜狐对比文："石昊是冲锋陷阵的猛将，叶凡是运筹帷幄的统帅"）。
  他"以力证道"的落点不是变强本身：「他的道从来不是为了自己成仙，而是为了让身边的人活下去，让脚下的土地不被践踏」。
- **叶凡**：沉稳内敛、极富谋略，"叶黑"之名——**看似腹黑实则重情义**；弧光是"从一个只想回家的平凡人，活成叶天帝"。
- **萧炎**：人物深度常被批评一般，但"燃"；核心是**"莫欺少年穷"**这条不服输的底色 + 三年之约这种"为一个承诺">
- **韩立**：谨慎算计、"眉头一皱，退至众人身后"——其实是苟道的另一支，"让读者觉得这才是真实修仙"。

### 提炼：**所有被记住的主角，都是"一个底色 + 一次背叛底色"**

| 角色 | 底色（90% 的时候） | 背叛底色的触发 |
|---|---|---|
| 李长寿 | 能不打就不打，先备三条退路 | 稳到最后稳不住 → 牺牲自己 |
| 石昊 | 你挡我我就打穿你，从不谈判 | 身后有人要活 |
| 叶凡 | 先算代价，永远留一手 | 兄弟的承诺 |
| 萧炎 | 不服输，当场就要还回去 | 为三年之约可以低头 |
| 韩立 | 退到众人身后 | 恩情 / 承诺 |

**这就是"金色词条"的真身：它不是一个形容词，是一个矛盾结构。**

## 4. 提案：词条四格（第三格是玄幻的命门）

```
底色（**D1 日常 / D2 有代价**）：<他在没被逼时怎么做；照习惯做会亏时还做不做>
破例（**D3**）：<锚点被押上赌桌的方式；或他在两样珍视的东西之间被迫选一个>
锚点：<他主动交付出去的那样东西；一个人、一间铺子、一句承诺>
代价：<每破一次例赔掉什么>
```

> **底色是两档不是一档**：D1 写"没人逼他时他是谁"，D2 写"要付代价时他还做不做"。
> 两档都要有，否则看不出他的边界在哪；而 D3 才是尖锐的那一条（§13.2）。

> **"破例"和"锚点"是同一条线的两端**：锚点是他放出去的那条缆绳，破例就是**有人拿这条缆绳当绳子勒他**。
> 所以写破例的时候不许写"必要时""危及生命时"这种笼统条件，必须写清**谁、拿什么、怎么押上桌**（详见 §13.2）。

### 为什么第三格在玄幻里是命门

作者 2026-10-28 的观察：玄幻里有一类角色**「修炼着修炼着就没有人味了，越近道越无情」**。
这不是个别写法，是题材自带的反向压力 —— 这个世界的规则本身在劝人**去人化**。

于是主角的闪光点不在"更强"，而在**「始终维系自己，哪怕只剩一丝人性」**。
而那一丝人性，通常不是他守住不放的，是他**主动交付出去的**——

> **人世间的锚点。**

它同时是三样东西：
- **他珍视的东西**（所以他会为它破例）
- **他的底线**（所以它一旦被碰，他会做平时不会做的事）
- **他还是人的证据**（对标"越近道越无情"：别人在丢，他在交出去）

⇒ 所以"锚点"不是 `motivation` 那种"我要变强"，它必须是**具体的、可被夺走的、且他已经为它付过代价的**一样东西。
**锚点被夺走，是全书最重的一次事件**（见 §12 的三层维护）。

**为什么必须四格齐全**：
- 只有底色 → 角色扁平（一路苟 / 一路莽），读者会腻，模型也没有变化空间；
- 只有破例 → 没有可预测性，等于随机；
- 没有锚点 → 破例没有正当性，读者判定为作者开恩；**而且在这个题材里，没有锚点的角色会自己滑向"无情"** —— 那正是反面角色。

**判据（可机检）**：
- J1 底色必须是**动作模式**，不是形容词（"先备三条退路"可以，"谨慎"不行）；
- J2 破例必须指向**一个具体处境**，且这个处境能在一卷里出现（不是"必要时"）；
- J3 破例必须**付代价**（他要为这次背叛底色赔掉什么，写死）；
- J4 锚点必须是**一样具体的东西**（一个人、一本账、一句承诺），不能是"尊严""信念"这类抽象词；
- **J5 锚点必须是他"交出去"的，不是他"守住"的**：能说出一句"他为此放弃了什么"。

> **"破例"这一格同时是成长轴**：它只写"起点在哪"，不写"终点在哪"。
> 终点由 §6 决定——**底色不动，门槛往下移**。所以词条不是一次性设定，它自带一条可以走三卷的路。

## 5. 词条库草案（4 条，可直接覆盖）

> 词条是**作者选的**，不是模型生成的。模型只在四格之内演绎局面/倾向/位移。

**① 稳健型**
- 底色：未虑胜先虑败；能不交手就不交手；每次出手前先备三条退路
- 破例：有人**因为他的"没出手"**死了（不是因为他出手）
- 锚点：他已经算进"我要保"那份名单里的人
- 代价：每破一次例，名单上就多一个人，退路就少一条
- 弧光：从"只保自己" → "保到保不住为止"

**② 以力证道型**
- 底色：不绕路；谁挡就打穿谁；从不谈判
- 破例：有人愿意替他挡
- 锚点：他答应过的事（哪怕对方已经死了）
- 代价：每破一次例，就欠下一条新债
- 弧光：从"为自己争" → "为身后的人争"

**③ 算计型**
- 底色：先算代价再动手；能借力绝不自己上；永远留一手
- 破例：算出来的最优解要求他**放弃某一个人**
- 锚点：他记的那本恩账（仇账可以慢慢清，恩账必须当场还）
- 代价：破例的那一次，账算错了，而且要自己认
- 弧光：从"只算自己的账" → "替别人算账"

**④ 反派型（魅力反派，作者点名过阿蒙那种）**
- 底色：把所有人当变量；享受过程；从不守别人定的规则
- 破例：遇到一个他**算不准**的人（不是更强，是算不准）
- 锚点：他的"趣味"——他要看到结局
- 代价：算不准的人会让他失手一次
- 弧光：不需要正向；**只要"能理解"**（判据是"换我在他的位置、拿着他的信息，我也可能会这么选"）

## 6. 成长性：底色不变，**破例的门槛下移**

> 作者补充（2026-10-28）：「那个胆小鬼，在金色词条加持下，到了后期他可能**依然胆小，依然害怕**，
> 但为了自己所珍视的人或者事，他**愿意直面恐惧**，这就是成长。」

这一条把之前没讲清的冲突解决了。原先写「成长 = 状态分布的均值位移」（WTT），
容易读成「性格变了」；而如果性格真的变了，金词条就被冲掉了——后期那个人已经不是开篇那个人。

**精确表述**：

```
成长 ≠ 底色位移
成长 = 破例条件变宽 / 破例门槛下移 / 破例代价他认了
```

底色的众数**不动**（他依然胆小），动的是**分布的低端尾巴**——他愿意走到的那个极端。

### 三种可观测的成长形态

| 形态 | 长什么样 | 例（胆小鬼） |
|---|---|---|
| **门槛下移** | 同一类处境，以前要付更大的代价才动，现在小一点也动 | 以前「自己会死」才拼命 → 后来「同门要死」就出手 |
| **范围扩大** | 能让他破例的对象变多 | 以前只为自己 → 后来为名单上的人 |
| **代价认了** | 破例之后不再事后后悔、不再自我辩解 | 手还在抖，但不再跟自己说"这不关我的事" |

### 判据（G 系列，可机检）

- **G1 底色必须还在**：后期那一条里要能看见他原本的动作痕迹（先退半步 / 先算退路 / 手抖耳鸣）。
  「他不再害怕了」不算成长，**那是换了一个人**。
- **G2 必须能看出方向**：同一类处境，前期他逃、后期他站住。
  如果两期写出来一模一样，那是**没成长**，不是"稳定"。
- **G3 位移要落在门槛上，不落在性格词上**：
  写「从 只有自己会死才拼命 → 同门要死也出手」可以；
  写「从 胆小 → 勇敢」不行——那是把底色擦掉了。

### 一个完整的走法（胆小鬼，三卷）

```
底色：先退半步，把话岔开，能不接就不接
破例：只有"自己要死"的时候才拼命
锚点：（开篇是空的 —— 这个空格就是全书要去填的东西）
成长：
  第1卷  只有自己要死才拼命。依然先退半步，但退的时候把身后的人挡了一下。
  第2卷  同门要死也出手。出手前还在算退路，算完还是去了。
  第3卷  不再需要"要死"这个条件。手抖、耳鸣，站到前面。
```

每一条都保留了「先退半步 / 算退路 / 手抖耳鸣」——**底色一字未动，动的是他愿意走多远。**

### 与 WTT 的关系（不是推翻，是收窄）

WTT 说人格变化来自「表现出状态的后果」，落在**分布**上。
我们这一层只取**分布的边界**：均值不动，尾巴伸长。
所以 `arc` 字段写的是「**破例条件怎么移动**」，不是「性格怎么变」。

## 7. 与现有字段的映射（零迁移）

| 词条格 | 落到哪 | 现状 |
|---|---|---|
| 底色 | `personality` 的 3–5 条 if-then（**其中一条必须是"反着做"的那条**） | 已有字段 |
| 锚点 | `motivation`（核心动机与渴望） | 已有字段 |
| 破例门槛的移动（不是性格变化） | `arc`（角色弧光） | 已有字段 |

⇒ **仍然不需要新增字段、不需要迁移。** 只是把写死的语义明确成四格。

## 8. 流程（落地后长这样）

```mermaid
flowchart LR
  A["作者选词条<br/>（从库里挑 1–2 条，或自写）"] --> B["展开成四格<br/>底色 / 破例 / 锚点 / 代价"]
  B --> C["题库只做翻译<br/>把四格译成行为样例"]
  C --> D["模型写 if–then<br/>局面 / 倾向 / 位移"]
  D --> E["卷纲 / 章纲选择行"]
```

读法：**作者给种子，题库把种子译成可判的样例，模型只做演绎。**
模型从头到尾**不决定主角是谁**，只决定"在这条性格下，这一步具体怎么走"。

## 9. 与"随机"的界线

作者的原话是"随机不是我们想要的"。要写清这条界线在哪：

- **随机 = 让模型决定底色**（它可能给你一个活不下去的胆小鬼）；
- **不随机 = 底色与锚点由作者覆盖，只把"这一步具体怎么做"留给模型**。
- 模型的自由度是**战术级的**（这一章他先要册子还是先找人），不是战略级的（他是谁）。

## 10. 不做的事

- 不引入 MBTI / 九型 / 阵营标签（见 `character-disposition-questionnaire.md` §4）；
- 不做评分、不做稀有度数值（"金色"是比喻，不落字段）；
- 不把词条写进模板 `content`（那是死信，见 `character-dynamics-effective-site.md`）；
- 反派与卷级核心的覆盖**留到主角读数之后**再加（单一变量）。

## 11. 驱动机制：题库不是机制，**引用才是**

> 作者的追问：「怎么让这种性格描述形成一套**驱动机制**，它不能只停留在描述的层面。
> 而这种驱动机制恰恰是上一个版本你描述的那种场景问题，你觉得怎么样？我不确定这样能不能生效。」

**判断：不能。** 题库放在"写作时"会失效，理由有三：

1. **题库是静态的，剧情是动态的。** 这一章的压力是"赵铎递了状纸"，不是题库里的通用题；
   硬要套，就得先把真实处境"翻译成题库里的一道题"——那一步翻译全靠模型自觉，等于没有约束。
2. **SJT 本身就是"低仿真"的**（OPM 的定性：low-fidelity simulation）。用它当**选拔/摸底**工具可以，
   当**逐章决策器**精度不够——它测的是"这类人一般怎么选"，不是"这个人此刻怎么选"。
3. **成本翻倍**：每章多一次调用、多一套输出格式，而收益只是"看起来更细"。

⇒ **题库的正确位置是"建卡时用一次"**（把词条译成 if-then），之后**它就该退场**。

### 真正的驱动：让性格变成**可寻址**的东西

现在是"模型读完一段描述，自己决定听不听"。改成"模型必须引用某一条，且引用会被校验"：

**第一步 · 编号**（不改字段，只改写法）

```
D1  日常档：局面 <没被逼时那类事>   倾向 <习惯动作>＋<身体反应>   位移 <…>
D2  代价档：局面 <照习惯做会亏的事>  倾向 <还照不照做>＋<身体反应>   位移 <…>
D3  破例档：局面 <锚点被押上赌桌>    倾向 <第一秒做的事>＋<身体反应>   位移 <…>   ← 必须存在
```

编号不是编号，是**档位**：D1/D2 决定"他平时是谁"，D3 决定"他真正在乎什么"（详见 §13.2）。
下游引用 `D3` 时，等于在说"这一章碰到了他的锚点"——**这本身就是一条剧情强度信号**。

**第二步 · 选择行必须引用**

```
选择：<力源> —— <他做了什么>｜否掉了 <…>，因为 D2：<他哪一条不容许>
```

原来写的是"因为 <他的哪一条>"——**这五个字就是"描述层"和"机制层"的分界线**：
写"因为他的性格"永远能过关；写"因为 D2"可以被查。

**第三步 · 三条体检**（`arc-position.ts` 同族，加在拍子体检旁边）

| 码 | 判定 | 治什么 |
|---|---|---|
| `ARC_CHOICE_NO_D` | 选择行没有出现 `D<n>` | 模型绕过性格自由发挥 |
| `ARC_CHOICE_UNKNOWN_D` | 引用了一个角色卡上不存在的编号 | 引用是编的 |
| `ARC_CHOICE_SAME_D` | 连续 3 章引用同一条 | 只用一条倾向推所有局面 ⇒ 角色扁平 |

这三条合起来，才叫"性格驱动选择"：**不是性格被描述得多细，是它被引用了多少次、引用得对不对。**

### 加一条软性要求（不可机检，但必须写）

引用之后还要回答一句：**这一章的局面，和 D2 的局面是同一类吗？**
不是同一类却引用了，就要说明为什么这条倾向在这里适用（比如"这是 D2 的变体：拿走的东西换了，但他不能接的条件没变"）。
**说不出来 = 引用是凑的。**

## 12. 三层动态维护：表层会变，底色只加深

> 作者 2026-10-28：「水面上的性格可能被任何事件改变，比如乐观开朗的大男孩遇到灭门惨祸，
> 他不可能还开朗得起来，那还是个人吗？但他底色里的重情重义，**可能反而变得更深刻、更珍视**。」

所以"维护性格"不是"更新那个字段"，是**分层各管各的**：

| 层 | 内容 | 变不变 | 落在哪 | 谁改 |
|---|---|---|---|---|
| **表层** | 气质、情绪、说话方式、乐观/阴沉 | **会被事件改变**，且应该变 | `cs_mental_state`（章级，已有） | 每章 |
| **底色** | D1–Dn 的行为倾向 | **不变**；只允许两个方向：**加深** 或 **磨钝** | `personality` | **只在卷末**，且须登记 |
| **锚点** | 他交出去的那样东西 | 可被**夺走 / 替换 / 新增** —— 这是全书最重的事件 | `motivation` + `arc` | 卷末 |

### 关键约束

- **表层变 ≠ 底色变。** 灭门之后他不再开朗（表层变了），但重情重义更狠了（底色加深）——**这两件事必须同时写在卡上**，
  否则模型会二选一：要么"他还是那么乐观"（假），要么"他黑化了"（换人）。
- **底色只能加深或磨钝，不能换。** 「从重情义 → 变得冷血」不是成长也不是维护，那是**换了个角色**（除非这是反面弧光，见反派词条）。
- **锚点被夺走必须是一次登记过的事件**，并且要同时写：他因此失去了什么（表层）／底色往哪个方向加深（底色）／新的锚点是什么（或"现在是空的"）。
- **锚点空着的角色最危险也最好看**：他此时没有理由做人，模型必须回答"他靠什么撑住这一段"。

### 判据（M 系列）

- **M1** 一个卷末里三者都写全了：表层变了什么、底色往哪个方向动了、锚点还在不在；
- **M2** 底色那一条如果是"变了方向"（不只是加深/磨钝），必须标注为**反面弧光**，否则视为崩人设；
- **M3** 锚点被夺走的那一卷，必须有一个"此后他为什么还活着"的答案（哪怕答案是"还没想好，但他记着那件事"）。

## 13. 局面 / 倾向 / 位移 的**内容规格**

> 作者 2026-10-28：「我认可你的局面/倾向/位移那一套，但是里面到底是什么内容，这个得好好商讨一下子。
> 里面的事件必须**具有代表性**，它未必是真实发生过的，但**必须符合性格**。」

### 13.0 先认一处表述错误

上一轮我写「题库不能当驱动机制，建卡时用一次就退场」。这句话把我自己绕进去了：

- **退场的是"提问"这个动作**，不是它的产物；
- 题库的产物 = 一堆**行为样例**（局面/倾向/位移），它们留在卡上，**一直就是模型做选择时的参照系**；
- 所以"驱动 = 比对参照 + 引用编号"（§11），而参照物就是题库译出来的那几条。两者不是对立关系，是同一件事的两端。

**一句话**：题库负责**造参照物**，编号引用负责**逼模型用参照物**。

### 13.1 修正一条过严的判据

上一版我要求「局面必须写成条件句，不许写事件句」。**这过严了** —— 条件句写出来干巴巴，没有画面，也不像人。

按作者口径改：

> 允许**以事件的形式**写，但必须是**可替换的原型事件**。

判定只需要一句：**同一个局面，能不能替换成三个不同章节里的具体版本，而倾向不变？**

| | 例子 | 判定 |
|---|---|---|
| ❌ | `灵配袋空一格，几日之内要凑出保命开销` | 这是**开场的状态**，换个时间不成立 → 一次性 |
| ❌ | `同门当众递状纸，要他认一笔旧账`（倾向绑死在"状纸"上） | 换契据/名册就不成立 → 绑死了具体道具 |
| ✅ | `有人当众拿出一样他签过字的东西，要他当场认` | 状纸、契据、门规画押、试药名册都能套 → 原型 |

> ⚠️ 最后这条**只过了"可替换"这一关，没过尖锐度关**——聪明能救他（翻册子、对日子）。完整的合格例子见 13.2。

### 13.2 三条倾向不是三件事，是**一个人面对三档压力**

> 作者 2026-10-28 最终澄清：「**尖锐度只是我举的例子**，想要说明的是，局面/倾向/位移列出来的举动和反应
> **必须具有代表性，不能像日记一样**。具有代表性的话，那自然得有**层次感**。
> 因为尖锐度的场面描述的是**背叛底色的触发**，而不是**正常底色**。」

这一句把我前面两版的毛病一起点破了。之前我把"尖锐"当成**每一条**的要求，结果：
- 每条都要"刀架脖子" ⇒ 角色一天到晚被逼到极限，那不是人，是连续剧；
- 每条都不痛 ⇒ 又退回"聪明人的操作手册"。

**正解：三档压力，三个答案，同一个人。**

| | 档位标签 | 局面长什么样 | 测的是 | 要不要尖锐 | 条数 |
|---|---|---|---|---|---|
| **D<n>** | **〔日常〕**（没被逼） | 他按习惯就会遇到的那类事 | **他是个什么样的人** | ❌ 不必，但要有代表性 | 1–2 |
| **D<n>** | **〔代价〕**（要付点什么） | 照习惯做会亏，他要不要照做 | **他的边界在哪** | ❌ 不必，但要有取舍 | 1–2 |
| **D<n>** | **〔破例〕**（锚点被押上桌） | 他**极少遇到**的那类事 | **他真正在乎什么** | ✅ **必须尖锐** | **恰好 1** |

所以完整的卡是这样（同一个底色，三档递进）：

```
D1〔日常〕  局面：<日常那类事>            倾向：<习惯动作>＋<身体反应>   位移：<…>
D2〔代价〕  局面：<照习惯做会亏的那类事>   倾向：<这次还照不照做>＋<身体反应>   位移：<…>
D3〔破例〕  局面：<锚点被押上赌桌>        倾向：<第一秒做的事>＋<身体反应>   位移：<右端＝这一条的倾向>   ← 尖锐
```

> ⚠️ **编号是条目号，不是档位**（2026-10-29 改）。旧口径写「编号就是档位」，
> 结果模型写第四条时只能编出「D4 代价档」，档位与编号当场打架。
> 现在编号只负责**引用寻址**（`因为 D2`），档位是编号后面的方括号标签。

**D1/D2 不是废条**：它们决定"这个人平时是什么样"，也是 D3 之所以有冲击力的对照。
没有前两档的日常，第三档的破例只是"又一个紧急场面"；有了前两档，读者才知道**他为了这件事破了自己多少规矩**。

**反过来也成立**：如果 D1/D2 写得也像 D3 一样刀光剑影，读者会疲劳，而且看不出他在"日常"里是谁。

#### "不能像日记"是什么意思

两个意思，都要避开：

- **不写流水账**：不写"他某天早上做了什么"，写"他**总是**怎么应对这一类事"；
- **不写时间线上的一次**：一旦加上日期、地点、具体人名，它就变成一次事件 —— 那是情节大纲的活，不是性格卡的活。
- 一句话：**写原型，不写记录。**

#### 2026-10-29 第三版实测：三个错同时出现

作者拿到生成结果后的原话：

> 「还是不对，不仅仅是依旧和剧情有关，而且 **D3 档不过是主角日常罢了，和位移也对不上**。」

逐条对：

| 生成出来的 | 错在哪 | 补的闸门 |
|---|---|---|
| `局面：照规矩钻漏洞要多耗三天，绕开就得再吞一口残简` | 「残简」「灵配袋」「因果纹」「内门残卷」全是**本书专名**，换个世界就听不懂 | **禁本书一切专名**；判定＝念给没看过这本书的人听，他要先问「XX 是什么」就是设定 |
| `D3 局面：有人把他签过的字摊上桌…倾向：抓过状纸说「这字我不认」` | 对陈砚这种人，**被逼认账就顶回去**是他天天干的事 —— 这是**日常 + 更用力**，不是破例 | **〔破例〕必须与〔日常〕反方向**；对调两条倾向，读者必须觉得不对劲 |
| `D3 倾向：这字我不认` ／ `D3 位移：肯为别人的账出一次手` | 两者**毫无关系**：拒绝认账 ≠ 替别人背账 | **〔破例〕的位移右端，必须就是这一条自己的倾向** |
| `D3 破例档` … `D4 代价档` | 编号被当成档位，第四条只能编出一个不存在的档 | **编号是条目号，档位是方括号标签**；〔破例〕恰好一条 |

加一条**局面层面的**闸：〔破例〕的局面必须是**他极少遇到**的那类。
他隔三差五就碰上，早有一套熟练应对 —— 那叫日常，不叫破例。这一条和"反方向"是同一个病的两种表现：**一个说局面不够新，一个说动作不够反。**

**改后的对照**（同一个人：死面理工脑、只算自己那本账、一碰落笔就压不住火）

```
D1〔日常〕
局面：有人口头给他一句保证，说凭据事后补，眼下就要他先信
倾向：不接话，先问凭据在哪；答不上来就把话岔开，手指在桌沿上敲两下
位移：从 当场应下 → 先要凭据，因为按过的那次手印没人替他认

D2〔代价〕
局面：守着规矩要多花几天，绕开就能快，代价是要动用一样他舍不得用的东西
倾向：还是守着，宁可慢；那东西收回去不动，喉咙发紧也不动
位移：从 缺什么就用什么 → 先算够不够再用，因为上一次用超了

D3〔破例〕
局面：他算出来的唯一生路，代价是放弃一个人；而那个人正看着他
倾向：他把算好的那条路划掉，签了，把这笔账记到自己名下
位移：尚无 —— 从 只算自己那本账 → 肯替别人的账赔一次本（本卷要去的地方）
```

对照三处都改了：
- D1/D2 的专名全换成通用词（凭据／一样舍不得用的东西），换任何修真或都市世界都读得懂；
- D3 的**倾向**从"不认"改成"**认**"——对一个"只算自己那本账"的人，替别人背账才是反方向；
- D3 的**位移右端**（肯替别人的账赔本）现在**就是它的倾向**，两头接上了。

### 13.3 尖锐度：只对 **D3（破例）** 考

> 作者 2026-10-28：「尖锐的问题应该是，如果有人拿刀架在你妈脖子上，让你跪下求饶，你会怎么做？
> 这个时候才能体现出真正的性格底色。这个问题**未必真的要有结果**（不同实力、不同局面，应对肯定不一样 ——
> 哪怕以力证道的主角，也不可能什么情况都直接冲上去被人一刀结果、全剧终），
> 但要从回答里**体现出行为模式**。」

这是本稿最重要的一次修正。我上一轮那个例子（`有人当众拿出一样他签过字的东西`）**不痛**，原因就一句话：

> **它还能靠聪明解决。**

而"刀架在你妈脖子上"之所以尖锐，是因为它**无解**，而且它**直接压在他最珍视的那样东西上**。**但它只属于 D3。**
如果把这条标准套到 D1/D2 上，你会得到一个每章都在生死关头、读者三天就腻的角色。

#### 尖锐度判据（只考 D3）

> **这一局里，聪明能救他吗？**
>
> - 能 → 这是一道**智力题**，测的是他多会算；
> - 不能 → 才是**性格题**，测的是他愿意付什么。
>
> 加一问：**把这局里"他能算的部分"全拿掉，还剩什么？**
> 什么都不剩 = 算术题；还剩一个必须选的东西 = 性格题。

#### 尖锐局面的定义：**锚点被当成人质**

```
尖锐局面 = 有人拿他最珍视的那样东西，逼他做他最做不出的那件事。
```

这一句同时缝住了三处：
- 它解释了**为什么尖锐**（不是利益受损，是锚点被押上赌桌）；
- 它解释了**破例条件**（§4 第二格）到底怎么写——**破例就是锚点被当人质的那一刻**；
- 它保证了**测出来的东西是他**（别人的锚点不同，同一个局面逼出来的动作就不同 ⇒ 天然排他）。

#### 三条倾向的验收（按档位分开，别混着判）

| 档 | 验收标准 |
|---|---|
| D1 | 换成三个具体版本仍成立（可替换）＋ 是动作 ＋ 有身体反应 |
| D2 | 同上，且**能看出他在哪里开始犹豫 / 开始付代价** |
| D3 | 同上，且 **聪明救不了他** ＋ **赌注是他的锚点** |

#### 允许"没有结果"——但必须"有第一反应"

作者点得很准：不同实力、不同局面，应对肯定不一样，硬要写"他冲上去了"就是把人写成傻子
（"别人一刀结果了，然后全剧终"）。

所以**倾向不写结局，只写他做的第一件事**：

```
倾向：<他第一秒做的事>＋<一个身体反应>
```

例（同一个锚点、同一个无解局，三种底色）：

| 底色 | 第一秒做的事 | 身体反应 |
|---|---|---|
| 死面理工脑（算） | 先开口拖时间，同时用眼角量对面那只手到人质之间的距离 | 指节发白，声音一点没抖 |
| 以力证道（莽） | 一句话不说就往前半步，把距离压到对方必须先动 | 手心在出汗，但脚没停 |
| 苟道（退） | 慢慢跪下去，跪的过程里把袖口那截东西挪到能拿到的地方 | 膝盖在抖，眼睛一直盯着那只手 |

三个人**都没有赢**，也都不需要赢。但三种行为模式一眼可辨——**这就是用户要的"从回答里体现出行为模式"**。

#### 身体反应是硬要求

不是文笔修饰，是**可观测证据**：它证明"他还在怕，但仍在做"（对应 §6 的 G1，也是"底色没变"的唯一外部证据）。
没有身体反应的倾向，一律视为"作者替他写了个聪明方案"。

### 13.4 倾向：三条规格

1. **是动作**，能拍出来（"先开口拖时间，同时量距离"可以；"谨慎"不行）；
2. **排他**：套到另一个角色身上**不成立**（三个人的锚点不同 ⇒ 同一个局逼出的动作就不同）；
3. **可失败**：这个动作有时候会**害了他**（只赚不赔的是外挂，不是性格）；
4. **带身体反应**：见 13.2 末。

### 13.5 位移：三条规格（承接 §6）

1. 移动的是**门槛**，不是性格词；
2. 有**代价**；
3. 能说出**因为哪件事**。

### 13.6 三条终极判据（人判，不用机器）

**① 尖锐度**
> 这一局里，**聪明能救他吗**？能救 ⇒ 是智力题，重写。

**② 代表性**
> 把三行读给一个没看过这本书的人听，他能不能说出「**这是个什么样的人**」？
> - 说得出 → 有代表性；
> - 只能说出「他很聪明 / 很谨慎 / 很会算」→ **那还是策略，不是人**。

**③ 可替换**
> 把这个人换成另一个人（锚点不同），这段三行**还成立吗**？成立 ⇒ 你写的是"一般人"，不是"他"。

三条合起来，正对应作者的原话：**尖锐的局面 + 可辨的行为模式 + 只有他会这么做**。

### 13.7 关于动态调整的成本（回答作者"不知道成本如何"）

| 方案 | 成本 | 抖动风险 | 建议 |
|---|---|---|---|
| 每章调整底色 | 每章多一次调用 | **高**（同一件事前后判不一） | ❌ 不做 |
| **卷末调一次 + 事件触发** | 一卷一次 | 低 | ✅ 做这个 |
| **只守底线 / 锚点** | **零调用** —— 只需体检与拦截 | 无 | ✅ 现在就能做 |

**守底线这件事根本不需要"调整"，它只需要"检查"**：
锚点和底线一旦写进卡，卷级体检只要回答一句「这一卷有没有人碰了他的锚点、他有没有按底线反应」。
那是 M 系列的活，不生成、不调用、不重写角色卡 —— **成本可以忽略**。

所以顺序应该是：**先守底线（零成本、立刻可做）→ 再谈卷末加深（一次调用）→ 最后才考虑逐章维护（不建议）**。
