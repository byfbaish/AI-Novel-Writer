## 0. 本稿对上一稿的修正

上一稿把三条（动机 / 禁区 / 恐惧）下沉到一条 Lie，方向对，**落点错了**：

| 上一稿 | 本稿 |
|---|---|
| 深层恒定，全书不变 | **表层可变，按卷位移** |
| 禁区 = 否决条件（二值，出现即违规） | **倾向 = 权重（连续，有档位）** |
| 破禁区是唯一例外 | **破就是成长，是常态** |

错的根源：**否决条件天生不可变**。二值变量没有"成长"这个中间态——要么守要么不守。而作者要的是
「原来只会逃 → 慢慢敢于面对 → 把在乎的人护在身后 → 一人独断万古」这种**连续位移**。连续性只能在权重上做，不能在否决上做。

## 1. 出处：两句话，两个学科

### 1.1 「性格决定命运」不是俗语，是断片

赫拉克利特，三词残句 **ἦθος ἀνθρώπῳ δαίμων（ethos anthropoi daimon）**，编号 D 119 / K 114。

- 常见译法："a man's character is his fate" / "character is destiny" / Kahn 译 "a man's character is his divinity"。
- **歧义全在 daimon**：可作"命运/命数"，也可作"神性"，而荷马语源义是「分配、分得一份的人」（Kahn, p. 261）。
- 取荷马义直译更硬：**「性格，就是他所分得的那一份」**——不是外部掷给他的签，是他自己的形状决定了落到他头上的是哪一份。这比"命运"更贴本稿机制：性格不是被命运决定的，**性格是筛子，命运从筛眼里落下来**。

### 1.2 「倾向性」有精确形式：CAPS 的 if–then 特征

Mischel & Shoda (1995) 认知-情感人格系统（CAPS）：人格的稳定单元不是形容词，而是**情境-行为特征**（behavioral signature）：

> **if 情境 X，then 行为 A；if 情境 Y，then 行为 B。**

两条关键性质（原文）：

1. **跨情境的变异不是噪声，它就是人格本身**——"It makes variability of behavior across situations an essential reflection of the stable personality system and indeed its distinctive signature."
2. **情境换了，行为跟着换，但两者之间的对应关系是稳的**——"When the *ifs* posed by the situation change, so do the *thens* generated by the personality system, but the relationship between them is stable."

**这就是作者说的"选择的倾向性"，而且它天生可判**：局面是固定的自变量，行为是因变量。同一局面下行为变了，就是位移；变了又没有登记，就是走形。形容词做不到这一点——"他很勇敢"无法回答"这一章他该不该逃"。

### 1.3 「性格作为状态维护」也有名字：WTT

Fleeson & Jayawickreme (2015) 整体特质理论（Whole Trait Theory）：

- **特质 = 状态的密度分布**（density distribution of personality states），不是一个数，而是整条分布（均值、最小、最大、方差）。
- 变化的驱动（原文）："**Personality changes primarily because of the consequences of manifesting states.**"
  人格主要因为「表现出某个状态所带来的后果」而改变。

这一句正好是作者那句话的理论版：**他每一次破例，后果落回他头上，下一次同类局面的分布就移了。**

**所以「性格是状态」并不是把性格降格成情绪，而是**：
- 单次行为 = state（可波动，允许反常）
- 倾向档位 = 分布的均值（按卷移动）
- 成长 = **均值位移被登记**，不是某一次发挥超常

## 2. 形式：性格 = 一组 if–then + 当前档位

### 2.1 写法

```
局面：<一类会反复出现的压力，写情境不写情绪>
倾向：<他在这个局面下通常怎么做>
位移：<第 X 卷，因为 <哪件事>，从 <旧做法> → <新做法>>
```

三条要求（都是硬约束）：

1. **局面必须可复现**。"被人当众质疑"可复现；"心情低落时"不可复现（那是情绪不是局面）。
2. **倾向必须是一个动作**，不是形容词。「先退半步，把话岔开」是动作；「谨慎」不是。
3. **位移必须写清"因为哪件事"**。没有事件支撑的位移，就是作者硬掰。

### 2.2 例子（主角）

```
局面：对方比自己强，且当场有人看着
倾向：先算退路，再决定要不要动（从来不是先上头）
位移：第 1 卷末，因为妹妹被扣在赌坊，从「转身就走」→「站住，把话说完」

局面：有人白给他好处，且对方不图回报
倾向：不接。宁可自己多绕三步
位移：第 2 卷中，因为老周把药塞给他就跑了，从「追上去还钱」→「收下，记着」

局面：在乎的人被当着他的面威胁
倾向：不谈条件，先动手
位移：（尚无 —— 这是他要走到的地方）
```

第三条没有位移，是**故意的**：它是这一卷要走到的地方。用户给的那条轴（逃 → 面对 → 护住 → 独断）就是连续几条 `then` 的位移累加，不需要另设"等级阶梯"。

### 2.3 为什么不用形容词清单

| | 形容词（"勇敢/谨慎/腹黑"） | if–then |
|---|---|---|
| 可判 | ✗ 无法回答"这章他该不该逃" | ✓ 局面出现，行为可对照 |
| 可变 | ✗ 只能整体换标签 | ✓ 换一个 then 就是一个档位 |
| 可检出走形 | ✗ | ✓ 未登记的 then 变化 = 走形 |
| 能生成 | ✗ 模型只能往形容词上靠 | ✓ 给出局面就能问"他会怎么应" |

## 3. 三条判据

| # | 判据 | 不过怎么办 |
|---|---|---|
| **K1 可复现** | 这个局面在本卷会**再出现至少两次**吗？ | 只出现一次的是情节，不是性格。删 |
| **K2 有来处** | 能一句话说出"他吃过什么亏才变成这样"吗？ | 说不出 ⇒ 贴标签。**不必写进字段，但要过这一问** |
| **K3 位移有后果** | 登记了位移的那一章，他付了什么代价？ | 没代价的位移 = 白送成长，等于没成长 |

**K3 是本轮最要紧的一条。** 它直接对上 WTT："变化来自表现状态的后果"。破例而不担后果，读者看到的是作者开恩，不是人物长大。

### 3.1 一条反滥用条款

上一轮我写"禁区不许有例外"，本稿改为：

> **单章之内，倾向没有例外；卷内允许位移，但位移必须登记，且必须付代价。**
>
> **未登记的 then 变化 = 走形，重写；登记了但没付代价的 = 白送，重写。**

这条同时解决了"破禁区算成长"与"破禁区算崩人设"的界线：**界线不在破没破，在有没有账。**

## 4. 覆盖分层（按现有 `role` 字段，不新增枚举）

| 角色 | 要求 | 理由 |
|---|---|---|
| `protagonist` 主角 | **3–5 条** if–then，至少 1 条有位移记录，至少 1 条位移空白（那是本卷要走到的地方） | 全书唯一的完整曲线 |
| `antagonist` 最大反派 | **至少 1 条** if–then，且必须过 K2 | 魅力反派靠"他的逻辑成立"，不靠"他坏" |
| `supporting` 卷级核心 | **1 条** if–then | 只在**以卷为单位**的核心角色上要；`minor` 一律不要 |
| `minor` | 不要 | 给配角写倾向，只会让所有角色同质 |

### 4.1 反派特则

用户点出：「相当多读者吃魅力反派那一套，比如《诡秘之主》的阿蒙」。

反派的判据与主角**不同**，不能共用一套：

| | 主角 | 魅力反派 |
|---|---|---|
| 成立条件 | 读者**认同**他的选择 | 读者**理解**他的选择，但不认同 |
| 判据句 | "换我我也想这么干" | **"换我在他的位置、拿着他的信息，我也可能会这么选"** |
| 常见失败 | 太顺、没代价 | 只写了坏，没写他的 if 是什么 |

所以反派的 if 必须**是被逼出来的局面**，then 必须**在他看来是正确的**。他不需要自我怀疑，但他需要自洽。

**反派也可以是反向位移**：主角从"逃→面对"，反派从"信人→不信人"。方向相反不算违规，**没有方向**才算。

## 5. 接到现有链路

### 5.1 与章级状态的分工（重要）

现有 `characters.cs_*` 六槽（`location` / `powerLevel` / `physicalState` / `mentalState` / `keyItems` / `recentEvents`）是**章级**、按章刷新、带 field-level provenance 与 `upToChapter` 快照。

**倾向不进这六个槽。** 理由：那六槽每章都会变，放进去就等于把性格降级成情绪（`mentalState` 已经是"这章他什么心情"）。两者粒度不同，混在一起会互相覆盖。

| | 章级状态 | 性格倾向 |
|---|---|---|
| 粒度 | 每章 | **每卷** |
| 载体 | `cs_*` + `cs_provenance`（已有） | 角色卡文本字段 + 行式位移记录 |
| 消费 | 正文链 / 审稿链（`character-state-lines.ts`，已有） | 选择行判定 + 蓝图 purpose 继承 |

### 5.2 与选择行的接线

上一轮的选择行：`选择：<力源> —— <他做了什么>｜否掉了 <他本可以做的>，因为 <他的哪一条>`

本稿把「他的哪一条」确定为**某条 if–then 的当前档位**，判定变成三步：

1. 这一章的压力，属于哪一条 `if`？（对不上任何一条 ⇒ 这一章没有性格戏，只是过场，允许）
2. 他做的，是这个 `if` 的当前 `then` 吗？
   - 是 ⇒ 正常，不需要解释；
   - 不是，且本卷已登记位移 ⇒ 正常，正文要写出**位移后的第一次**；
   - 不是，且未登记 ⇒ **走形，重写**。

这把上一轮那条模糊判定（"理由指不回动机/禁区/恐惧 ⇒ 模型替他选的"）换成了**可机检的三分支**。

## 7. 不做的事

- **不下沉到 Wound/Lie**（作者已裁定）。K2「有来处」只作自检一问，不设字段。
- **不预设成长阶梯**。"逃→面对→护住→独断"是**一种**轴（承担轴），不是通用等级。别的角色可以是反向轴、横向轴；只要求位移**有方向**，不要求方向一致。
- **不给配角写倾向**，`minor` 一律不写。
- **不把倾向做成数值**（如"勇气 +1"）。数值会让模型开始优化数字，而不是写人。
- **不自动重跑架构链**：已存在项目的角色卡没有 if–then，沿用"已存在项目不自动重跑"的既有约定，由作者决定何时重生成。
