# 性格从哪来：前史问卷，而不是未来剧情

> 状态：待裁定（2026-10-28）· 设计稿，未落代码；「题库用途」已由下一行修正为翻译而非测量
> 触发：作者读 `detailTask` 后指出方向问题 ——
> 「局面里提到要在本卷里至少出现多少次，这不就在暗示要结合剧情给性格吗？但性格的底色是由**过去的经历**形成的，
> 它决定的是**未来**选择的倾向性。从未来剧情里提炼出性格，这是不合理的。」
>
> **本稿结论：作者判断成立，且错的不只是一条判据，是整条因果链的方向。**

## 1. 错在哪：因果链被倒置了

```
   过去（他经历过什么）
        │  ✅ 正确的方向
        ▼
   性格（if–then 倾向：这类处境下他会怎么动）
        │
        ▼
   未来（这一章他选哪条力源）
```

现行条款把第三环写成了第一环：

> 「局面必须可复现：**本卷至少还会再出现两次**。」

这句话让作者（模型）**先想本卷要发生什么剧情，再从剧情里抠出一条"性格"**。于是产出的其实是
「本卷剧情的摘要」，不是性格。上一轮实机读数正是这个形态：
`局面：同门当众递状纸` = 第一章的事件，`局面：灵配袋空一格` = 开场的状态。

**判据要锚在过去，不是锚在未来。** 一句可替换的话：

> 这个局面必须是**他过去反复遇到过的那一类**（所以才长出了这条倾向），
> 不是「本卷要安排两次」的剧情配额。

「可复现」仍然保留，但它复现的地方是**他的前半生**，不是接下来的 21 章。

## 2. 业内四类方法（查证，均有出处）

| 方法 | 是什么 | 出处 | 对我们的用处 |
|---|---|---|---|
| **情境判断测验 SJT** | 给若干个真实情境 + 若干反应选项，答「你**最可能**怎么做」 | OPM（美国人事管理局）"Situational Judgment Tests"；Wikipedia；NHS HEE SJT 指南 | **作者描述的就是这个**，见 §3 |
| **两难故事法** | 给一个没有正确答案的两难，**不问选什么，问为什么** | Kohlberg《Heinz 偷药》；科普中国「两难故事法」；Cross-Cultural Research on Kohlberg's Stages | 判据来源：**理由才是指标**，选项不是 |
| **阵营九宫格** | 两根轴：对规则（守序↔混乱）× 对他人（善↔恶） | D&D 1977 Basic Set；Gygax 1976 文章；Wikipedia "Alignment (D&D)" | **两根轴几乎就是我们的力源轴**，但只借轴、不借标签 |
| **角色问卷 / 人物小传** | 50–370 道题的人物档案 | Novakovich 1995（Open University 收录）；Gotham Writers 的普鲁斯特问卷；alanwatt.com 模板 | 题型参考；**同时是最该警惕的一类**，见 §4 |

## 3. SJT 就是作者说的东西，但有两种版本，只能用一种

OPM 与 Wikipedia 都写明 SJT 有两种问法：

| 版本 | 问法 | 测到的是 |
|---|---|---|
| **knowledge-based** | 「哪一种做法**最有效/最合适**」 | 他知道什么叫对 —— **理想人格** |
| **behavioural tendency** | 「你**最可能**怎么做」 | 他实际会怎么做 —— **这个人** |

Wikipedia 原文点明：`behavioural tendency questions correlate more highly with personality`。

⇒ **只能用后者。** 用前者生成出来的是「他应该成为的人」，不是「他是谁」——
那正好是我们一直在防的"六选项全都能选的角色 = 没有性格"。

SJT 的另一条硬事实：它是**定制工具**，不是通用题库（*not acquired off-the-shelf*），
题目必须从"该角色会遇到的关键事件"生成。
这一条和我们"不能从剧情反推性格"不矛盾：**题目从"人一生会遇到的抉择类型"来，不从本书剧情来。**

## 4. 三个必须避开的坑（每个都有出处）

**坑一：产出类型标签。**
九宫格 / MBTI / 九型都会收敛成"守序善良""INTJ"这种词。而 Gygax 本人后来弃用了阵营系统
（"caused so much misunderstanding and confusion"），社区批评它"90% 的人落在善/中立"。
⇒ **只借它的两根轴，绝不产出类型词。** 答案必须落成**具体动作**。

**坑二：题目与本书的世界不搭。**
Kohlberg 方法有效性的第一条是：dilemma 必须 *real to the particular people involved* ——
必须踩到当事人真正在乎的价值。中文研究里还有一个佐证：用"孝道故事"测中国人，得分高于标准故事，
因为标准故事里的"公平"对那批被试不是核心议题。
⇒ 题目要保留**结构**（两个价值对撞），**改写情境**（修真世界的制度：契据、名分、荐额、人情）。

**坑三：问卷把人拆成零件。**
wille.org 明确警告：把角色拼装成一堆档案细节，结果会是 `cookie-cutter writing`；
alanwatt 的判据是 "details need to earn their place by connecting to the dilemma"。
⇒ 题库**只问两难**，不问"最喜欢的颜色"。每一题都必须两条路都付代价。

## 5. 提案：8–12 道前史两难题

**题型**（固定句式，答案必须是动作）：

```
一、<一个他真实可能遇到的处境，两条路都付代价>
  他实际上会：<具体动作>
  因为：<理由；指得回他吃过的哪次亏>
```

**覆盖面**（四组轴，直接对应下游的力源选择）：

| 轴 | 两难长什么样 | 对应力源 |
|---|---|---|
| 规则 vs 变通 | 照规矩走会输，绕过去会背一个名 | 规则 / 破 |
| 自己 vs 在乎的人 | 保自己稳，还是保他不死 | 自己 / 他人 |
| 眼前 vs 长远 | 现在拿得到，将来要还 | 交换 |
| 名分 vs 实惠 | 要脸，还是要那笔东西 | 交换 / 他人 |

**答案怎么用**：把「处境 + 动作 + 理由」**翻译成三行式**
`局面 / 倾向 / 位移` —— 理由里出现"吃过亏"的，就是位移的出处。
**不产出类型词，不产出评分。**

**判据（可机检的部分）**：
- J1 每条倾向的局面里**不含**本作专有名词（人名、地名、契据名、章节事件）；
- J2 至少 1 条倾向**对他不利**，且说得出他因此吃过什么亏；
- J3 至少 1 对倾向**互相打架**（同一处境下想做两件相反的事），且写明他先服从哪一条；
- J4 3–5 条里至少能导出**两种不同的力源**（全导到"规则"= 同一条，重写）。

## 6. 与现有链的接法

```mermaid
flowchart LR
  A["前提 / 主角档案<br/>（只有穿越前寥寥数语）"] --> B["前史两难题 8–12 道<br/>（新增阶段）"]
  B --> C["翻译成 if–then<br/>局面 / 倾向 / 位移"]
  C --> D["角色卡 personality"]
  D --> E["卷纲（读 characters_arch）"]
  D --> F["章纲选择行（力源 + 否掉了什么）"]
  E --> F
```

读法：**题库插在角色卡之前**，它只吃"人这一生的抉择类型"，不吃本书大纲。
这样即使主角前史只有两句话，也能长出稳定倾向 —— 因为问的是"这类处境他会怎么选"，不是"他经历过什么"。

## 7. 分期与成本

**第一步（可立刻做，改文本）**
- 删掉 `detailTask` 里「本卷至少还会再出现两次」→ 改成「他**过去**反复遇到过的那一类」；
- 补 J2（至少 1 条对他不利 + 说得出吃过什么亏）、J3（至少 1 对互相打架）、J4（至少导出两种力源）；
- 中英同步 + 守卫断言。

**第二步（结构变更，需单轮）**
- 新增「前史两难题」阶段（题库 + 答题 + 翻译），插在 `character_dynamics` 之前；
- 题库本身进 `src/shared/`（与 `story-beats.ts` 同级，单一事实源）；
- 涉及：架构链多一步、`detailTask` 收缩为"按问卷结果写三行式"、已存在项目不重跑。

**不做**：不引入 MBTI / 九型 / 阵营标签；不做评分；不把题库写进模板 content（那是死信，见 `character-dynamics-effective-site.md`）。

## 8. 一句话

**性格不是从"这一卷要发生什么"里推出来的，是从"他这辈子已经答过哪些题"里推出来的。
我们能给他的前史只有两句话 —— 那就换一种问法：不问他经历过什么，问他在那些路口会往哪边走。**
