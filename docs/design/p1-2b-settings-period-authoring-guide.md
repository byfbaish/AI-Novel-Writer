## 1. 为什么要做

P1-2a 只做到了「按**整节**投影」——把 `### 3.【隐喻与深层危机】` 整节边界化，省约 **5%**（ch2 实测 896 字 = user 的 5.2%）。

**真正的大头在 `### 1.【核心规则与体系漏洞】`**（世界观里体量最大的一节）：它的期次信息**混在句内**，例如「**前期**他用『信息隔离』自我催眠……**中期**他发现反面用法……」。框架**不做语义解析**（B′ 段二 Q4 的既有纪律）⇒ 这种「一段跨两期」的写法，**机械手段切不开**。

⇒ 要让正文链能「只下发与本章同期的设定」，只能给设定加**机读的期次**。这就是 P1-2b。

## 4. 形态 ② 的具体操作

### 4.1 在哪编辑

编辑器 → **世界观** 文件（`WorldBuildingEditor.tsx`，与世界观.md 同源；改完即落 `project_core.worldbuilding`）。

### 4.2 加什么

沿用两条既有先例的**同形**写法：
- B′ 段二的机读行：`老陈记｜hours=07:00-09:00`
- §3 的期次清单：`- 前期：…` / `- 中期：…`

⇒ 建议在条目**首行行尾**追加一段机读标注，例如：

```
**漏洞二：载体盲区。**｜stage=early,mid
```

> ⚠️ **格式以设计稿最终裁定为准**（英文键 vs 中文键、单期 vs 多期、是否允许 `ch1-30` 章范围）。本文只确认**动作量与可行性**，不锁定语法。

### 4.3 要标哪 12 处

- **§1（6 处）**：漏洞一（前期自我催眠 / 中期反面用法）、漏洞二（前期试错 / 中后期成法则）、漏洞三（全书张力）、漏洞四（中期核心武器）、漏洞五（本作后期实验区）、元知识段。
- **§3（1 处）**：那条「最大谜团递进结构」——**照抄现有四行即可**，无需改写。
- **§4（5 处）**：「长期舞台（全书反复出现）」+ 云创大厦 / 人才服务中心档案库 / 白鹭湾 / 跨线天桥——这几处文本里**已经写了**「全书反复出现」，只是要变成机读。

### 4.4 失败回退

1. **动前先备份**世界观文本（复制到项目 `prompts/` 下任一 `.md`，或手抄一份）。
2. **逐条可逆**：删掉 `｜stage=…` 即恢复原状，不影响正文。
3. **框架侧 fail-open**（继承 P1-2a / B′ 的纪律）：**没标 = 不判 = 全量下发 = 保持现状**。⇒ 标一半也能跑，不会因缺标而报错或丢设定。
