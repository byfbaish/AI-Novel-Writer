# 世界观

### 1.【核心规则与体系漏洞】

**规则立法层——"谁在墙上写字"**

副本规则清单不是无意识生成的。每条规则有编号、有措辞、有标点习惯。沈舟在ch16首次注意到"禁止"和"不得"的混用出现在同一份清单里——同一个人写规则不会换同义词，两套措辞说明至少两个立法者。这个发现是G2"读规则"阶段的入口，也是全书主线"规则之上还有规则"的起点。

规则被写入副本的方式有三种，直接决定主角的破解路径：
- **刻入**：正常出现在墙上的规则，可读、可背、可拍照（但照片会模糊，只有人脑记下来的才算数）。
- **嵌入**：规则存在于场景物件里，不直接写在墙上。比如"无声公寓"的第六条被刮平之前，它其实写在楼道的消防栓玻璃内侧。这类规则铃会震。
- **写入**：规则正在被实时添加。主角在ch20后开始怀疑，有些规则是在他读到的前几秒才被"填"进去的——意味着立法者知道他在读哪里。

**规则漏洞的四种类型（主角的破解工具箱）**

- **字面漏洞**：规则语句的歧义。如"不得在午夜后开门"——门是指物理门还是"心门"？"无声公寓"里主角靠这个活过第一夜。
- **主体漏洞**：规则没有说对谁生效。"住户不得在走廊停留超过三分钟"——但沈舟那晚的身份是"访客"。换主体读，是G2的核心技能。
- **时序漏洞**：规则A和规则B各自成立，但同时执行会矛盾。例如"必须响应敲门声"和"不得与门外对话"——先响应再沉默？还是先沉默再响应？两者都触发死亡，除非找到第三条路。
- **自指漏洞**：规则指向阅读者自身。"本规则适用于所有读到它的人"——如果主角没有"读到"呢？让老猫读出来，自己听，是否算"读到"？这是G3之后的终极破局工具。

**铃的探针机制——分三级反馈**

- **单次微震**：附近有"不该存在的门"——可能是副本的出口、也可能是陷阱。铃不区分，只报告"异常"。
- **连续微震**：有被抹掉的规则空位——ch20被刮平的"第六条"触发过一次。震动持续时间与规则被抹的严重程度正相关。
- **震到发烫（烫手，但主角手不会真受伤，RL-002不触发）**：有更高维度的规则正在覆盖当前规则。这是G4之后的新信号，出现频率随主角接近"大幕"真相而增加。

铃的局限：它只告诉主角"这里有东西"，不告诉主角"这是什么"。它是探针，不是答案——这条定位是金手指不可突破的边界，防止无代价通关。

**体系漏洞本身的结构性冲突**

规则会被"打补丁"。当某个副本的通关率过高，立法者会追加规则或修改现有规则。修改的痕迹就是漏洞——新旧规则之间的接缝处，逻辑最脆弱。主角的核心战术不是找单条规则的漏洞，而是找两条规则之间的"接缝"。

这直接产生一个持续冲突：主角破解规则→通关率上升→立法者打补丁→补丁制造新接缝→主角利用新接缝。这个反馈循环是全书节奏的引擎。

### 2.【阶层断层与资源战场】

**玩家内部断层：老玩家 vs 新玩家**

老玩家（通关≥5场）掌握两样东西：一是"副本通识"——不同类型副本的通用规则模式（比如"午夜规则"几乎每场都有）；二是"脏情报"——有些秘密只有活过足够多场的人才知道，比如"国运值不只是数字，它会影响副本难度"。他们不分享，因为情报是硬通货。

新玩家（1–4场）只能靠弹幕和指挥中心喂的信息活。老玩家会故意给新玩家错误信息——不是恶意，是因为副本有时需要"弃子"。沈舟在G2阶段被老玩家坑过一次，直接导致他决定"不信任任何人，只信自己验证过的规则"。

**现实世界断层：指挥中心内部的三派**

指挥中心是华夏官方在"大幕"开启后紧急成立的机构，负责对接唯一玩家。内部不是铁板一块：
- **技术派**：试图用大数据和AI辅助沈舟破解规则。他们的建议往往"正确但慢半拍"，因为AI无法处理被抹掉的规则。
- **舆情派**：盯着弹幕，关注国运值波动和观众情绪。他们的决策依据是"怎么让观众打赏"而不是"怎么让沈舟活"。
- **留白派**：一小撮人，通过加密专线告诉沈舟"有些规则我们故意不告诉你，因为告诉你就死"。沈舟对他们的态度从愤怒到理解、再到主动配合——这是G5前后的一条人物弧光。

**稀缺资源清单**

- **规则原文**：完整、未经篡改的规则清单。绝大多数玩家只能拿到残本。主角靠铃的探针+自身推演重建。
- **被抹规则的情报**：知道哪条规则被抹过，以及被抹前的内容。全服不超过三人掌握这个信息。这是最高价值情报。
- **SAN恢复剂**：副本有概率掉落（约15%）。可以在结算通道交易，但价格极高。主角从未买过——他靠"规则推演"本身作为SAN管理机制（推出一个规则，理智值消耗减半）。
- **信物**：观众打赏的兑换媒介。信物本身不可转让，但信物兑换的道具可以在副本中暂时借给他人。主角的首个信物来自ch7一个匿名弹幕——至今不知道是谁。
- **"白名单"名额**：传言指进入结算通道后可以不扣国运值获得补给。主角怀疑这是真的，但获得白名单的条件没人知道。

**主角的位置与争夺对象**

沈舟无后台、无组织、无启动资金。他的资源只有一个铃（探针）和一个脑（推演）。他争夺的对象是：
- 向老玩家争夺**规则解释权**——谁有权定义"这条规则是什么意思"
- 向指挥中心争夺**自主决策权**——他在ch25后不再无条件接受指挥中心的建议
- 向弹幕争夺**信任**——弹幕的"共情"阶段在ch40后才会出现，之前全是嘲讽和质疑

### 3.【隐喻与深层危机】

**"大幕"之前的谎言——190国的历史是拼凑的**

主神空间对外宣称"190国随机抽取"。但沈舟在G2后期开始注意到：不同国家的副本规则有相同的笔迹特征。像同一个设计师画了190张不同的施工图，但用的是同一把尺子。

更深的线索：被抹掉的国家。平行旁闻（≤3处/卷）中会出现"原本有193国"的模糊信息。那消失的3国是怎么没的？国运归零=抹除，但"抹除"不是死亡——是**记忆删除**。世界上已经没人记得那3国的名字，但沈舟的妹妹语音里出现过一个他听不懂的词。那个词可能是其中一国的国名。

**历史禁忌：不能问"大幕之前"**

玩家之间有一条不成文禁忌：不要在副本里问"大幕之前你记得什么"。问了的人，下一场副本难度会异常上升。没人知道是惩罚还是巧合。主角在G3阶段试探性问过一次——铃震了。

**被掩盖的真相：妹妹的语音不是发给他的**

沈舟手机里妹妹的语音，内容是一段日常叮嘱。但在G2一次SAN值低谷时，他发现语音中有0.3秒的异常波形——那是一个被剪辑进去的频率信号。妹妹可能不是发语音给他，是**通过他传递信息**。这段语音可能在某个特定副本中，作为"钥匙"或"弱点"被使用。这是全书情感锚点与悬念锚点的重合位，在G8-G10之间引爆。

**终极灾变：立法者不止一层**

"大幕"不是自然现象。规则清单上的人为痕迹指向一个结论：有多个层级的立法者在互相覆盖对方的规则。最下层的立法者可能就是上一轮大幕的幸存者——他们通关后没有离开，而是被"录用"成了规则书写员。主角要面对的终极问题不是"怎么通关"，而是"通关后我会变成什么"。

### 4.【空间结构（地图与区域）】

**主神空间（The Main Space）**
- 定位：所有副本的容器与全球玩家的唯一中转站。零点开启、零点结算，只在两场之间存在的白色虚无空间。
- 关键规则：非副本期间唯一可停留空间；不能主动移动，只能等待分配；说话会被全世界听到——所以老玩家在这里基本沉默，信息交易靠比手势。
- 长期舞台（每次副本前后短暂出现，G4后逗留时间延长）。

**结算通道（The Settlement Passage）**
- 定位：主神空间内的一条独立支路，仅当玩家从副本生还后开启，用于兑换补给和恢复。
- 关键规则：只能向前走，不能回头（回头会随机丢失一件道具）；物资扣国运值，价格指数上升——同样的道具第二次买价格翻倍；通道尽头不定时出现"白名单"入口，但进入条件不公开。
- 长期舞台（两场之间的固定场景，主角的A4背面记事主要在这里完成）。

**无声公寓（The Silent Apartment）**
- 定位：首个副本（ch1–10），D阶"闻声"。一栋六层独居公寓，每层有6个房间，住户身份为"独居者"。
- 关键规则：① 住户不得在走廊发出超过30分贝的声音；② 午夜后不得响应敲门声；③ 不得打开没贴门牌的门；④ 每天早上检查门缝下的纸条，纸条上的内容每天变化；⑤ 不得在走廊停留超过3分钟；⑥【已被刮平·内容未知】。
- 一次性场景（首副本，用后不再进入），但其中的"被抹规则"机制是后续所有副本的预演。

**指挥中心（The Command Center）**
- 定位：现实世界中华夏官方设立的专门机构，通过加密专线（"那根线"）与沈舟通信。与主神空间是"外层/内层"关系——指挥中心只能单向下达建议，无法替玩家做决策。
- 关键规则：专线通信有30秒延迟；专线内容会被主神空间记录（沈舟知道，指挥中心不知道）；指挥中心的建议被污染时，专线里会出现固定的白噪音——这是沈舟自己发现的识别方法。
- 长期舞台（贯穿全书，但语气和决策权重随G阶段推进而变化）。

**弹幕层（The Barrage Layer）**
- 定位：观众看到的直播间界面，叠合在副本空间之上。玩家能看到弹幕，但不能删除或屏蔽。弹幕分为普通弹幕（免费）和打赏弹幕（带信物）。
- 关键规则：弹幕不能被玩家主动回复——只能通过行动让弹幕"解读"；违规弹幕会被系统自动过滤（但主角发现过滤词表是可以被观众绕过的）；弹幕情绪影响国运值波动率——观众越"沸腾"，国运值单次波动越大。
- 长期舞台（全书固定界面层，三阶段演进：嘲讽→沸腾→共情）。

**现实层（The Real Layer）**
- 定位：大幕开启后的2028年华夏，与主神空间平行存在。国运值直接影响此层的物理稳定性——国运值下降时，现实层会出现"抹除"现象（建筑、道路、人名从现实中消失）。
- 关键规则：国运值归零=全国被抹除；只有弹幕观众记得被抹除的国家曾存在；现实层中的普通人不知道"大幕"的存在，但偶尔会梦到副本场景。
- 长期舞台（与主神空间交替出现，在G5"国运初醒"后成为独立的叙事空间）。

**待验区（The Pending Zone）**
- 定位：沈舟自己命名的个人备忘空间。指他在结算通道里靠墙站立时，用A4纸背面写下"待验"规则条目的那一小块区域。不是主神空间给的空间，是他自己"划出来"的。
- 关键规则：只有他一个人在这里写东西不会被弹幕完全解读；如果他在待验区写下的规则条目在下一场副本中被验证为真，该条目自动刻入他的长期记忆，不再消耗SAN值。这是主角对抗SAN衰减的私人机制。
- 长期舞台（G2起固定出现，是主角的"主场"）。

少比喻、少通感、少拟人、少意象堆砌，修辞预算留给伏笔与钩子。

叙述贴着主角主观感官走，把冷硬客观叙述换成人物体感视角。

气质：死面理工脑——短句切分 + 计数口令，一句一击。

角色情绪外露（恐惧、愤怒、紧张要写出来），但叙述语气克制（不煽情、不升华、不点题）。

恐惧与紧张靠生理反应呈现（僵、麻、发凉、指尖收紧、手抖、出汗），不写心理告白。

对话只承载推进剧情的信息与人物的声线差异，不写成说明文。

弹幕独立于主角视角，只做反应，不代入主角情绪，不替主角推理。弹幕语言用【】括起来。

氛围细节允许留白，刻意不解释。规则清单的原文呈现：一句一段。

【网文"黄金第一章"创作法则】
1. 开场即高能（黄金三秒）：绝不要用长篇大论介绍世界观。起笔第一句必须直接切入一个动作、一次高压审问、一场追杀或一个极具落差感的嘲讽现场。
2. 仅当【本章信息】明确要求时才展现主角的金手指；不得为满足通用套路擅自新增事件。
3. 视角内推进：通过动作、感官、内心活动和符合当前视角的对话推动剧情；不得仅为展示信息而让角色公开说出只由其私下感知、尚未转述的内容。
4. 落实全局写作要求，避开其中列出的写作问题。

关联女性不可被真正侵犯（威胁可写、未遂可写、既成事实零容忍）；主角不可逆残损；主角不出卖国运；感情线不背叛。

怪谈必须有规则与代价，不写成纯灵异吓人。国运值不可无限回复。主角不靠他人喂答案通关。通关必须付出代价，且代价必须在前文有铺垫（读者能回溯到代价的来源）。

【精确度】

精确是稀缺的修辞资源，只在有分量的地方使用，禁止扫描式精确堆砌。

· 装饰性精确（型号、键位、材质规格）→ 降维或删除；判据：主角此刻真会注意到、且承担情绪或伏笔吗。

· 数据性精确（国运值、排名、存活数、倒计时、编号）→ 必须精确。

· 数量多用相对量词；只在全书唯一锚点保留精确数字。同段内精确数字/规格合计 ≤2 处。

· 精确度随紧张度上升：开头模糊，越接近爆点越聚焦。允许「记不准」，关键时刻再突然精确。

【真人叙事·最高优先级】

1. 拒绝工整闭环，禁止每段都「环境→动作→心理→总结」；允许叙事跳跃与省略，但因果链不能跳。读者可以不知道「他怎么知道的」，但不能不知道「他为什么这么做」。

2. 打散均匀长短句，杜绝连续同结构句式与排比。主叙述句 7–15 字，描写句 15–25 字，多用短句切分与计数口令。

3. 紧张场景先写生理反应，再补环境，不先铺白景再写人。

4. 删除说明式、总结式、解释式旁白。发生即发生，不解释原因、不帮读者复盘。

5. 保留人类微瑕疵：允许轻微不完美语序、短句骤停、思绪断点。

6. 能用动作体现心理就绝不直说；禁止「他意识到／他确认／他发现／他判断」。

7. 禁止状态确认句（「X 能/不能」「X 没 Y」「他还在/不在」）。状态必须通过动作或生理反应呈现。

8. 禁止连续三个句号短句，每句不超过 5 字。这不是短句切分，是列表。

9. 禁止对称句式、每段等长、升华口号、空洞心理告白、把对白写成说明文、章末内心独白或状态总结。

10. 去书面化：改用网文写实口语。

【爽点】

五类型：打脸、收获、揭秘、升级、被认可。每章至少 1 个，类型必须轮换，不能连续三章同一类型。禁止连续两章无 payoff。

【钩子】

每约 800 字一个推进或钩子；前 300 字内立张力。

章末钩子必须是具体型（揭示／行动／威胁／疑问），类型必须轮换，不能连续三章同一类型。禁状态描述型钩子。

每章第一句必须是动作、对话或异常现象，不能是环境描写或状态描述。

【黄金三章】

第 1 章：前 300 字必须有冲突＋钩子＋金手指展示＋主角核心特质。

第 2 章：必须有至少一次小爽点，必须建立主角的独特优势。

第 3 章：必须有一个完整的小闭环，必须有章末大钩子。

【段落与对话】

手机端每段 3–4 行（60–110 字），单段不超过 120 字。对话占比 25%–40%。

【弹幕】

每条 ≤20 字，每段 ≤5 条。允许错别字、有情绪、有跑题；禁止格言腔、点题式弹幕，禁止把弹幕写成主角内心独白。

【情感线】

正牌 0 或 1。暧昧不超过 5 个，可以同时存在，但不同时进入情感高潮。每个必须有独立功能（递线索／给资源／制造冲突／情感慰藉），不做花瓶。

【世界关系】

以主角为中心，但主角不是全知全能。禁止写与主角当前冲突无关的平行旁闻。允许写与主角当前冲突直接相关的跨线信息（如反派动向、指挥中心决策），但每卷不超过 2 处。

【修稿／精修时适用】

## 一、国运直播体系参考

### 1、《国运直播：我满级天师，你让我进规则怪谈？》

✅可借鉴（机制思想）

1. **双重信息差机制**：副本内天选者看到一套规则；全球观众的大屏幕会看到另外一部分隐藏信息。观众看得见，主角看不见，制造张力。

> 
> 你的改造：不要做成系统主动给观众爆料。可以设定：直播镜头会捕捉副本中部分画面，但存在大量信号丢失、画面畸变，**观众看到的也不一定是真相，同样会被副本迷惑**，避免观众开上帝视角碾压主角。

2. **直播即是副本的一部分**：直播不只是外部转播，副本诡异本身可以利用直播信号、弹幕进行干扰，而不是单纯旁观者。
❌禁止照搬：天师天赋、道法战斗、国家失败直接天灾毁灭的粗暴奖惩。

> 
> 你书里：**没有超自然天赋，沈舟纯靠逻辑；国运奖惩要做更含蓄，不是地震爆炸，现实层面缓慢渗透污染**。

### 2、《全球直播：我偷穿了整个怪谈世界》

✅可借鉴（国运绑定现实的设计思路）

1. 通关 / 死亡会对现实世界产生连锁反馈，但不是简单 “赢了全民加 buff，输了大地震”。可以有外交层面、社会舆论层面、心理层面的影响。
2. 全球多国外交频道、各国专家解读的生态，怎么写弹幕、评论区、现实网络舆论。
❌禁止照搬：窃取改写规则的特殊天赋，主角特殊能力。

> 
> 你的改造：沈舟**没有能力篡改规则**；专家解读可以大量出错，专家也会被误导，增加现实线的复杂性。
