## 0. 一句话结论

上级稿把 P1-2 写成「L2 投影：`architecture` 对正文只给事实源」，但**它自己的 §3 表又说落点"应是架构产出时的结构，不是正文侧的事后过滤"** —— 同一份稿子两处落点互斥（§2）。本稿先用实机 trace 量清楚「事实源里到底有多少是远期」，给出**三条可分离的候选**与实测数字，并把落点矛盾交作者裁定。

**实测结论**：纯框架侧能拿到的载荷削减上限约 **5.3%**（user 消息），因为远期/近期的分界**大多落在同一节内部**，而设定文本没有期次结构。要做到上级稿设想的「只给事实源」（本稿估 ~50%），必须给设定加**期次结构**——那是独立机制（§4-D）。

### 1.4 远期内容的实际形态（ch2 请求里模型看到的东西）

`### 3.【隐喻与深层危机】`（964 字）原文包含：

- 「**终极谜团：能力不是天降的，是被「写」进来的。**」
- 「**零号档案。** 市人才服务中心负一层的纸质档案库里，有一格空的抽屉…」
- 「**合照里少一个人。** …主角做的第一个大谎——"我升职了"——成真那天，他发现那张照片里空的那块变小了一点。」
- 「**最大谜团递进结构：** 前期…中期…后期…**终局：他必须回答——是他编辑了现实，还是现实早已被谁编辑过他。**」
- 「**终极灾变：现实变薄。**」「**主角的终极抉择：** 要留住「自己」，还是留住「世界」。」

⇒ 写**第 2 章**时，模型手里握着**终局谜底**。这正是上级稿 P1-2 要治的「长线设定进当前章节的错觉」——而且比"错觉"更硬：**剧透面**。

### 1.5 为什么远期/近期分界大多不可机械切分

同一节内部混着两期。例：`### 1`（2,433 字）的「可操作漏洞清单」：

- 「前期他用「信息隔离」自我催眠…**中期**他发现反面用法…」→ 两期并陈
- 「**中后期**他摸清规律并形成「载体法则」，这是他最值钱的底牌」→ 远期
- 「漏洞五…这条边界是**本作后期**最危险的实验区」→ 远期

⇒ **按标题切分只能解决"整节远期"的那两处**（§1.3 表里标"远期/半远期"的两节）。要让 P1-2 达到"只给事实源"，必须让设定文本**自带期次结构**（§4-D）。

它的三条纪律**逐条适用于 P1-2**：

## 4. 候选方案（三条可分离，实测数字）

### A. 远期节**边界化**（推荐 · 框架侧 · 零标注）

按 §1.3 的**模板固定标题**定位整节远期者（本例 = `### 3.【隐喻与深层危机】`），把它替换为「标题 + 一行远期声明」，正文不再逐字下沉：

```
### 3.【隐喻与深层危机】
（本节是后文才展开的远期设定，正文不再逐字注入；本章不得提前写出其结论或明示，也不得写出相反内容）
```

| 指标 | 数值（ch2 实机复算） |
|---|---|
| `architecture` | 6,856 → **5,951**（省 905 = **13.2%**） |
| 占 user 消息 | 42.2% → **34.7%**（净省 **5.3%**） |
| 剧透面 | 终局谜底 / 三条线索 / 终极抉择 **全部不再进请求** |

- **远期节选取**：只取 `### 3.【隐喻与深层危机】`（模板定义 = 终极灾变/最大谜团 ⇒ 本质是剧透，不是当期事实源）。`## 悬念骨架` 建议**保留**（139 字，其"显性冲突线"对当期有用；且它已是被压缩过的摘要）。
- **不可机械覆盖的部分诚实留白**：`### 1` 里的"后期最危险的实验区""中后期载体法则"等**仍在**——不在本方案射程内（§1.5）。
- **风险**：低。fail-open（找不到该标题 → 逐字返回）；作者若在覆盖版改名 ⇒ 静默 no-op，**只会少省，不会多删**。
- **代价**：§3 内的**规则性**内容（如「代述禁忌」）一并消失；边界声明只能声明"不得相反"，模型看不到内容就无从避让。**这是本方案唯一的信息损失，需作者确认可接受。**

### B. 远期节**只加显式标注**（零信息损失版）

不改一个字节内容，只把远期节**搬进一个带边界标题的子块**：

```
- 【后文才展开的设定（不得提前写出其结论或明示，也不得写出相反内容）】
  ### 3.【隐喻与深层危机】
  …原文逐字保留…
```

- 载荷：**不减**（+约 60 字）；剧透面**不变**。
- 收益：只治"错觉"（让模型看见"这段是远期的"），不治病灶（剧透仍在请求里）。
- **与 A 的关系**：若作者认为"内容不能丢"，B 是退路；但**上级稿 P1-2 的收益（只给事实源 → 减载荷）拿不到**。

### C. 运行时合同补「远期边界」声明（零材料改动 · 建议一并做）

`generate-draft.command.ts:472 chapterExecutionContractText()` 是**运行时不可变合同**（首稿/续写/压缩共用，语言对称，不经模板 ⇒ 无覆盖版遮蔽风险）。它现在只说了**事件**维度：

> 「悬念按原文揭示时点处理，**留待后文的事不得提前写成已完成**」

**设定**维度是空的（`systemSuffix` 那句「本章暂不展开的事实也不得写出**相反内容**」只管"不矛盾"，不管"不提前揭示"）。补一条即可：

> 【远期设定边界】世界设定与故事架构是全书事实源，其中属于后文才展开的内容（尚未揭示的真相、终局谜底、远期阶段才启用的规则）本章不得提前写出其结论或明示；它仍是必须遵守的事实边界，不得写出相反内容。

- 载荷：0。剧透面：0 变化（若不开 A/B）。
- **风险**：中偏低 —— 措辞过强可能压制**合法伏笔**。缓解：句中已限定为"写出其结论或**明示**"（保留暗示空间）。
- 与 A 叠加时收益最大（材料里没有终局 + 合同明令不得提前揭示）。

### D. 期次结构（真正拿到"只给事实源"，需裁定 · 另立小项）

两条路径，**都与已落地机制同形**：

| | 路径 | 形状 | 前置成本 |
|---|---|---|---|
| **D1** | **产出侧机读行** | `world_building` / `premise` 模板：每个 `###`/`##` 节尾加一行 `展开期=第N章起`（与已落地的 **`空间名｜hours=｜entry=`** 机读约束行、【具名人物登记】**同形**） | 改内置 zh/en **+ 必须同步作者覆盖版**（否则白改——P0-3 教训）；**存量项目需重生成世界观**才有效 |
| **D2** | **作者侧段级标签** | `【展开期：第30章起】`（与 P0-2 的 `【适用：架构】` 同形，新轴；无标签 = 全量 = 旧数据逐字不变） | 框架侧零成本；作者需手工标注 6.5K 世界观 |

- **理论收益**：把 `architecture` 削到"当期事实源"（本稿按 §1.3 估算远期占比约 20–50%，取决于作者的标注粒度）。
- **可观测性**：需要 trace 侧报 `beforeChars/afterChars/droppedSections`（上级稿附录 D 已预留字段）。
- 建议：**另立小项**，等 A+C 落地、作者看到实际效果后再决定。
