# 番茄创作指导 · 拆分落位稿

对应关系（已核源码）：

- 「全局写作要求」= `NovelConfig.globalGuidance` → `NovelConfigEditor.tsx:506`
- 「文风配置」= `NovelConfig.writingStyle` → `NovelConfigEditor.tsx:522`
- 「节奏/风格指导（可选）」= `pacingGuidance` → `DirectoryConfigDialog.tsx:512`（**生成章纲时**弹的对话框里）

---

## 0. 拆分前先说三个问题

**① 你那两块其实是同一套规则写了两遍。**  
「文风配置」里那段是 AI 把「全局写作要求」复述＋压缩的结果 —— 段落纪律、节奏密度、伏笔回收、  
章末钩子、对话要求、对称句式……原封不动搬了一遍。同一份内容进两次请求，互相稀释。

**② 文风配置里混进了 5 项不属于文风的东西。**  
段落段数、节奏密度、伏笔回收、章末钩子类型、弹幕视角 —— 这些是可判定的**硬规则**，  
而文风槽位被模板 `systemSuffix` 明文降权：「文风仅用于选择表达方式，不是新增事实或事件要求；  
**无需逐条强行兑现**」。写在这里＝大概率不执行。  
（界面文案「AI 写稿/修稿时会**严格遵循**这里的风格要求」与实现不符，这点我记下了。）

**③ 数值有多个版本在漂移**，见第 4 节。

**拆分原则**：文风配置放「**取向类**」（不可判定，供模型选表达方式）；  
全局写作要求放「**可判定类**」（能验收的硬规则）；跨章的放「**章纲节奏指导**」。

## 1. 「文风配置」——只放技法与语感

```
维持 pulp 爽文基调：口语直白，情绪外露，压迫感强。
少比喻、少通感、少拟人、少意象堆砌，修辞预算留给伏笔与钩子。
叙述贴着主角主观感官走，把冷硬客观叙述换成人物体感视角。
气质：死面理工脑——短句切分 + 计数口令，一句一击。
冷静克制，不煽情，不升华，不点题。
恐惧与紧张靠生理反应呈现（僵、麻、发凉、指尖收紧、手抖、出汗），不写心理告白。
对话只承载推进剧情的信息与人物的声线差异，不写成说明文。
弹幕独立于主角视角，只做反应，不代入主角情绪，不替主角推理。
氛围细节允许留白，刻意不解释。
```

## 2. 「全局写作要求」——只放可判定的硬规则

```
【红线·命中即作废】
关联女性不可被真正侵犯（威胁可写、未遂可写、既成事实零容忍）；主角不可逆残损；
主角不出卖国运；感情线不背叛。

【设定禁忌】
怪谈必须有规则与代价，不写成纯灵异吓人。国运值不可无限回复。
主角不靠他人喂答案通关；通关必须付出可定位的代价。

【精确度】
精确是稀缺的修辞资源，只在有分量的地方使用，禁止扫描式精确堆砌。
· 装饰性精确（型号、键位、材质规格）→ 降维或删除；判据：主角此刻真会注意到、且承担情绪或伏笔吗。
· 数据性精确（国运值、排名、存活数、倒计时、编号）→ 必须精确。
· 数量多用相对量词；只在全书唯一锚点保留精确数字。同段内精确数字/规格合计 ≤2 处。
· 精确度随紧张度上升：开头模糊，越接近爆点越聚焦。允许「记不准」，关键时刻再突然精确。

【真人叙事·最高优先级】
1. 拒绝工整闭环，禁止每段都「环境→动作→心理→总结」；允许叙事跳跃与省略。
2. 打散均匀长短句，杜绝连续同结构句式与排比；叙述句 11–27 字，多用短句切分与计数口令。
3. 紧张场景先写生理反应，再补环境，不先铺白景再写人。
4. 删除说明式、总结式、解释式旁白。发生即发生，不解释原因、不帮读者复盘。
5. 保留人类微瑕疵：允许轻微不完美语序、短句骤停、思绪断点。
6. 能用动作体现心理就绝不直说；禁止「他意识到／他确认／他发现／他判断」。
7. 禁止对称句式、每段等长、升华口号、空洞心理告白、把对白写成说明文、
   章末内心独白或状态总结。
8. 去书面化：改用网文写实口语。

【爽点】
五类型：打脸、收获、揭秘、升级、被认可。每章至少 1 个；禁止连续两章无 payoff。

【钩子】
每约 800 字一个推进或钩子；前 300 字内立张力。
章末钩子必须是具体型（揭示／行动／威胁／疑问），禁状态描述型钩子。
每章第一句必须是动作、对话或异常现象，不能是环境描写或状态描述。

【段落与对话】
手机端每段 3–4 行（60–110 字），单段不超过 120 字。对话占比 25%–40%。

【弹幕】
每条 ≤20 字，每段 ≤5 条。允许错别字、有情绪、有跑题；
禁止格言腔、点题式弹幕，禁止把弹幕写成主角内心独白。

【情感线】
正牌 0 或 1。暧昧不超过 3 个，每个必须有独立功能（递线索／给资源／
制造冲突／情感慰藉），不做花瓶。

【世界关系】
以主角为中心，但主角不是全知全能。禁止写与主角无关的平行旁闻。

【修稿／精修时适用】
严格保留原文所有段落拆分位置，只修改段落内文字，禁止合并相邻段落、禁止新增分段。
```

## 3. 「节奏/风格指导」——移到生成章纲的对话框

> 位置：生成章纲时弹出的「**节奏/风格指导（可选）**」。  
> 理由：这些规则需要**全量章节视野**才能执行（模型得知道前 10 章用了什么类型），  
> 写在正文指导里是空转。

```
节奏配比：2–3 章一个小爽点，10 章一个中爽点，每卷一个大的。
爽点类型轮换：打脸／收获／揭秘／升级／被认可，连续三章不得同一类型。
钩子类型轮换：揭示／行动／威胁／疑问，连续三章不得同一类型；每个小爽点配一个章末钩子。
伏笔管理：剧情线索登记台账并设目标回收章，60 章内必回收；
线索三段式 埋→浮现→收（「浮现」＝换义，不是复述）；氛围细节刻意留白、不进台账。
世界关系：每卷安排 1–2 处跨线交汇，且必须与主角当前冲突直接相关；不写与主角无关的平行旁闻。
章节标题必须含具体信息，不能用抽象词（好：「零点抽取」「别答应」；坏：「开始」「危机」「真相」）。
```

> ⚠️ **与模板硬编码冲突，必须知道**：内置模板 `chapter_blueprint`（全量章纲）正文里硬写着  
> 「小高潮循环：**严格执行"3-5章一个小循环"**」（`builtin-prompt-templates.ts:838`），  
> 续写模板 `chapter_blueprint_chunk` 里也有一条「维持每 3-5 章一个小高潮的节奏」（`:914`）。  
> 这两句与本节的「2–3 章」**在同一个 prompt 里打架**。  
> · 本节文字落在 `{{pacing_guidance}}` 出口上，模板自己标了「★最高优先级★」（`:868`/`:941`），**通常能压住**；  
> · 想**彻底消除**冲突 → 在「提示词设置」里覆盖这两个模板，把「3-5」那句改掉（其余正文照抄，只动这一句）。  
> · 另有一处**不可覆盖**（写在代码里）：若叙事结构选「自由弧（freeform）」且未填「自由弧文本」，  
> 会拼一句「每10-20章有一个小高潮」—— `architecture-workflow.ts:331`。

## 4. 数值已定稿

| 项         | 定稿                                              | 落地位置                   |
| --------- | ----------------------------------------------- | ---------------------- |
| 叙述句长      | **11–27 字**                                     | 第 2 节【真人叙事】第 2 条 ✅ 已写入 |
| 暧昧上限      | **≤3 个**                                        | 第 2 节【情感线】✅ 已写入        |
| 单章段数下限 90 | **删除**（90×60=5400 字 > 每章 3000，与「每段 60–110 字」互斥） | 不写入                    |
| 小爽点间隔     | **2–3 章**（压过模板的 3–5）                            | 第 3 节，见上方 ⚠️           |

第 1 章金手指展示、第 2/3 章的具体要求，不写进「全局写作要求」／「文风配置」——  
用「世界观／初始设定」里的 `【第2章必现】…`，会进该章审稿冻结清单逐项核对。
