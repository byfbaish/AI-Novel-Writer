> 缘起：[`2026-10-25-oh-story-absorption/assessment.md`](../2026-10-25-oh-story-absorption/assessment.md) A1 —— 外部包 22 类风格检测器的阈值是用七猫 5584 章 + 黑岩 3983 篇校准的，我方目标平台是番茄与起点，**阈值不可直接搬**

> 边界：本文只记录来源、许可、规模、字段。**不下载正文、不转载正文片段**。判 ③ 类（许可不明/盗版聚合）只记「存在但不可用」，不给链接。

## 0. 三句话结论

1. **起点有 3 条合法来源，全部限定「非商业研究」或只发布元数据**；**番茄一条都没有**——全网能搜到的番茄「数据」只有非官方逆向 API 与字体解密下载器，不可用。
2. **没有任何公开材料发布过「某类 AI 句式在真人网文中的每千字频次 / 误报率」。** 我方 22 类阈值在公开世界**没有可对标先例**，只能自建。
3. 只含统计量、不含原文的公开材料**有**（CCL 2020 与 Glottometrics 2024），且许可干净——它们的价值不是给阈值，而是**校准我们的分词与分母口径**。

## 2. 四问

**Q1 有没有直接覆盖番茄/起点的公开语料？**
起点有 3 条，但都带「非商业」限制；**番茄为零**。番茄只进过学术研究（定性结论），没有配套数据发布，也不存在自助开放平台。

**Q2 有没有只含统计结果、不含原文的公开材料？**
有，但只到「分布量」这一层，**没有句式频次**：
- CCL 2020（起点 7,000 万字）给了字数/词数/标点数/句数/段数，可复算出 **标点≈84/千字、段≈10.4/千字、平均段长≈96 字、平均句长≈34 字、句≈29/千字**
- Glottometrics 2024 给了词频、词汇密度、Uber 丰富度、标点分布、平均段长、句长、nMDD

**Q3 最接近可用的替代方案？**
按合规性排序：① GuoFeng 中文侧（统计层最贴起点，但非商业）→ ② MultiGenre（量小、题材分层好，适合估「题材 × 句式密度」方差）→ ③ CCL 2020 + Glottometrics 的外部锚点（不重算，只用来验证我方分词口径有没有系统性偏差）→ ④ 番茄无合法替代，只能用我方自有稿件。

**Q4 最务实的校准路径？**
「内主外辅、按平台分档、以误报率为目标」：
1. 主校准集 = **我方已定稿章节**（唯一既商用又贴平台）。样本门槛：≥30 章 / ≥6 万字 / ≥3 题材 / 每章 ≥2,000 字（短文本方差会淹没阈值）
2. 阈值取真人分布的 **P95（advisory）/ P97.5（blocking）**，目标误报 ≤5% / ≤0.5%
3. 保留 MIN_HITS + PER_KILO 双门槛，并承认：章长 <1,500 字时 MIN_HITS 形同虚设
4. 外部锚点只做**口径校验**（句/千字、段/千字、标点/千字偏离 >20% ⇒ 先怀疑分词口径，不是阈值）
5. 番茄与起点**分开标定**；番茄样本不足时用保守系数并标「低置信度」，不要拿起点阈值直接判番茄稿
6. 报告必须带样本量（「n=32 章 / 7.1 万字 / 3 题材 / 误报 1/32」），<30 章只写区间不写点估计

## 3. 法律边界（硬约束）

- **正文一律不进仓库、不进发行包、不进测试基准。** 哪怕几章也越界。
- 数据集卡片上的 Apache-2.0 / CC-BY 由**上传者**声明，上传者不是权利人，声明不能溯及原著 ⇒ HuggingFace / ModelScope 上多数 `webnovel` 合集判 ③。
- GuoFeng 这类权利人自发布的语料虽干净，但**明文只许非商业研究**：可用于算统计量，不可进产品。
- 番茄/起点的非官方接口多绕过字体加密与反爬，除违反平台条款，还可能触及「规避技术措施」的独立责任。
- 产品里只保留：**统计量 + 我方自有语料算出的阈值**，并留存来源、许可、采集日期、样本哈希以备审计。
