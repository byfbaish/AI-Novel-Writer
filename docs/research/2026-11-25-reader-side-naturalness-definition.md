# 「读者侧自然度」判定定义（S2′ 口径件 · 2026-11-25）

> 授权：只读研究 + 新增本文件；未改代码、未做模型调用
> 用途：把 Goal 新口径里的「读者侧自然度」写成**判什么 / 谁判 / 多少样本 / 合格线**四格齐全的判定件，供 S3 直接用
> 上游裁定：主人 2026-11-25 改靶——不以通过任何 AI 检测器为目标，不追求「判别真人还是 AI」

---

## 0 一句话

**判「读起来有没有机械感、套路感」，不判「是不是 AI 写的」，不判「写得好不好」。** 主判据是一次人读（唯一人类＝主人）的二分判定，机器代理只用来排版与筛查，永不作判定键。

---

## 1 判什么（三个问题，逐篇作答）

判者每读完一篇，只回答三问 + 一个定位，**不写评语、不打文学分**：

| 问 | 题干（按此原话问） | 取值 |
|---|---|---|
| Q1 | 有没有哪一处让你觉得「这话不像有人在讲」？ | 有 / 无；有则标段号 |
| Q2 | 有没有「套路句」——否定式对举（不是…而是…）、结论式冒号、模板金句、章末总结陈词？ | 有 / 无；有则抄出那一句（≤30 字） |
| Q3 | 这一章的机械感有多重？ | 无 / 轻 / 中 / 重 |
| 定位 | 若有，集中在开篇段 / 中段 / 章末，还是分散 | 单选 |

**判什么、不判什么（写死，防止判据漂移）**：

- ✅ 判：机械感、套路感、出戏点（读者侧可感的「不像人说话」）。
- ❌ 不判：是否 AI 生成（不猜来源，也不奖励「看起来像人」）；文学质量高低（质量属另一课题，混进来会让判者按喜好打分）；剧情/人物好坏；字数、节奏是否「像网文」（那是平台规范，不是自然度）。
- ❌ 不用机器读数当答案：机器代理的 4-gram、密度、跳转率只用来**排序与筛查**，不作判定键。

> 为什么把 Q2 单列：套路句是**可复述的具体证据**（能抄出原句），比「我觉得不自然」更可核；Q1 抓的是没有固定句式但出戏的地方。两者合起来覆盖「机械感」的两条来源：模板化与语境断裂。

## 2 谁判

| 项 | 规定 |
|---|---|
| 判定人 | **主人本人**（本组唯一人类）。Bot 不代判、不代填三问、不做「预判供参考」 |
| 判几次 | 每篇**只判一次**，不重判、不复核、不改判（重判就是按结果挑样本） |
| 盲法 | 判者拿到的是**随机编号**的纯文本（`A-01…A-18`），看不到章号、条件（A/B1/B2）、生成时间；**同一章位的几篇不放在同一批里相邻出现**，由随机顺序决定 |
| 顺序 | 顺序由固定 seed 随机生成并记录在案（谁判、何时、什么顺序、每篇结论，全部留档） |
| 时长上限 | 单次 ≤ 90 分钟、≤ 18 篇；超时或疲劳即停，余下的另起一天，**跨批不得互相比较** |
| 机器代理的位置 | 只在盲评**之前**用于：①筛掉字数明显异常（截断件）②给盲评排期；不参与判定，不进判词 |

## 3 多少样本（给数，不给「建议多判」）

判据是**二元配对**（同章位两臂：有机械感 / 无机械感），用符号检验（sign test）算最小可判量，H₀＝两臂无差异（p=0.5）：

| 配对数 n | 全一致才显著（p 值） | 允许 1 对不一致（p 值） | 结论 |
|---|---|---|---|
| 6 | 6/6，p=0.0156 | 5/6，p=0.109 ✗ | 太脆，只能看方向 |
| 8 | 8/8，p=0.0039 | 7/8，p=0.035 | 可用但不容错 |
| **9** | 9/9，p=0.0020 | **8/9，p=0.0195** | **最小可判量（推荐下限）** |
| **12** | 12/12，p=0.0002 | **10/12，p=0.0193** | **默认量（容 2 对不一致）** |
| 18 | 18/18 | 15/18，p=0.0038 | 上限（一次判完 90 分钟内可承载） |

- **下限 9 对**：低于 9 对，只要出现 2 对反例就不显著，判不出东西；
- **默认 12 对**：容 2 对不一致仍显著（10/12），对判者疲劳留余量；
- **上限 18 对**：一次判完的上限，超过即分批，分批之间不可比；
- 单臂未配对（如只有 6 篇干预件、没有对照）时，**不出胜负结论**，只写「样本不足，仅区间」——沿用课题总纲口径。

## 4 合格线（三层，先立后判）

一条干预**算「有效」必须同时满足三层**，缺一层只能写「未测出差异」：

| 层 | 判据 | 数值 |
|---|---|---|
| **① 主判据（盲评）** | 配对中「干预臂机械感更轻」的对数占比 | ≥ 10/12（或 ≥ 8/9），即符号检验 p < 0.05 |
| **② 严重度** | Q3「中/重」篇数，干预臂 vs 对照臂 | 至少一侧下降 ≥ 2 篇，且反向不增加 |
| **③ 代理读数（辅）** | 机器代理同向 | 允许不一致，但若代理**反向**则在判词里点明冲突，不得隐瞒 |

**禁止的三种写法**：
1. 代理读数一致但盲评不显著 → 只能写「代理同向、人判未测出」，**不得写「有效」**；
2. 盲评显著但方向来自 1 篇极端件 → 必须在判词里点名那一篇，且不得升格为 P17；
3. 把「判者说读着还行」写成结论 → 判词只认 Q1–Q3 的计数，不认印象。

**不成立时怎么写**：写「本轮读者侧未测出差异（n=12，p=…）」，不写「该干预无效」，更不写「模型不遵从」——这是 S2 留下的教训。

## 5 与其它口径的边界

| 易混事项 | 本件口径 |
|---|---|
| **AI 标识义务**（《人工智能生成合成内容标识办法》2025-09-01 施行） | 与文风**完全分开**：写得让人读着不像机器，不等于可以不标识；产品侧仍按办法作标识，任何人不得以「读着自然」为由省略 |
| **通过 AI 检测器** | 不作目标，也不作副产品报数；判据里不出现任何检测器名称 |
| **机器代理指标（4-gram、连接词、跳转率）** | 只作辅证与筛查，不进判定键；读数冲突时以人判为准并留痕 |
| **文学质量** | 另一课题；本件不判「写得好不好」，避免判者按喜好打分污染机械感判定 |
| **P17 出厂质检** | 人判不可自动化，故 P17 只收机器可检项；本件的盲评结论只能作**干预是否该进 P17 的前置证据**，不能变成 P17 的运行时闸门 |

## 6 落地动作（谁跑、跑什么、产出什么）

1. **排版**（developer）：从实验产物生成盲评包——随机编号、去掉章号与条件、按 seed 排序、一章一篇、纯文本；
   ```bash
   node scripts/res/blind-pack.mjs --src .runtime/res-s2/texts-r1 --out .runtime/blind-pack-01 --seed 20251125 --slots 12
   ```
   产出 `A-01.txt … A-12.txt` ＋ `map.json`（编号↔章号/条件，**判者不可见**，由 admin 保管）。
2. **判**（主人本人）：一次判完 ≤18 篇，逐篇填 Q1–Q3＋定位，落 `.batch/night/reports/blind-review-01.md`（谁判、时间、顺序、逐篇结论）。
3. **计分**（QA 复算）：按 §3/§4 出配对表、p 值、严重度变化；qa 只核算法，不评价文本。
4. **结论**（产品经理起草、负责人终审）：只按 §4 三层写，缺层即降级表述。
