# 番茄 / 起点常驻分类 × 现有工作流边界估算

> 2026-10-28。目的：回答"我们这套工作流能装下市场多少类型"，为后续是否扩展维度提供依据。
>
> **这份是机制层估算，不是商业层估算。** 两站的分区在读、完读率、均订均不可得（平台不公开，第三方转述不可采信），因此下文的"能/不能"一律指
> **骨架能不能装下这个类型的核心机制**，与"这个类型赚不赚钱"无关。

## 2. 两站的分类骨架

### 2.1 番茄：主分类 + 三层标签

主分类必选且唯一；主题 / 角色 / 情节各最多两个，是**修饰标签**不是分类。可点名的主分类：

**男频**：都市高武、都市脑洞、都市日常、都市修真、都市种田、都市官场、传统玄幻、玄幻脑洞、东方仙侠、西方奇幻、悬疑脑洞、悬疑灵异、科幻末世、历史古代、历史脑洞、游戏体育
**女频**：现言脑洞、豪门总裁、青春甜宠、职场婚恋、民国言情、年代、宫斗宅斗、古风世情、星光璀璨、玄幻言情

第三方统计口径为"男频 19 题材 / 女频 18 题材"（2026-07 采集），与上表数量级一致。

### 2.2 起点：14 个一级分类

玄幻 · 奇幻 · 武侠 · 仙侠 · 都市 · 现实 · 军事 · 历史 · 游戏 · 体育 · 科幻 · 诸天无限 · 悬疑灵异 · 轻小说

两站的**结构差异**值得记一笔：番茄的"都市高武""玄幻脑洞""悬疑脑洞"这类名字，本质是
**"背景 + 机制"两段式命名**（都市+高武、玄幻+脑洞、悬疑+脑洞），说明番茄的分类轴是"读者预期"，不是"世界观类型"。
起点仍是"世界观类型"轴。**我们要对齐的是番茄那一套**——因为番茄的分类名直接对应读者的爽点预期。

## 3. 判定用的九个硬槽

现有工作流能被"分类"卡住的地方，全部落在这九个槽上。每个槽都是**必须能回答一个问题**，答不出就填不满：

| 槽 | 要求回答的问题 | 现落点 |
|---|---|---|
| S1 等级表 | 有没有可数的阶梯？每级的**卡点**和**升级代价**是什么？ | 世界观五维之一 |
| S2 硬刻度 | 读者能不能用**两个数**判断谁强？ | 灵光透体几层 / 连续运功几次 |
| S3 生死资源 | 有没有一样"没有它就到顶"的稀缺物？ | 筑基荐额 |
| S4 施压机构 | 谁在压他？凭**什么职权凭证**压？ | 执事房 / 戒律堂 / 度支房 |
| S5 金手指 | 采什么、从谁身上采、采的时候惹上谁？ | 吞噬载体 = 麻烦源 |
| S6 两级结构 | 卷 = 世界和他都换了状态；单元 = 一段对峙局面 | 卷 / 单元 |
| S7 逼法五档 | 压力按**程序**升级：关心→标价→立卷→债务→摊牌 | 单元标注 |
| S8 交手六类 | 这一段怎么交手：堵门/谈判/取证/设局/摊牌/认账 | 单元标注 |
| S9 正文链 | 章末具体钩子 + 爽点五型 + 2500 字 | 正文模板 |

**这套九槽的真骨架是三件套：资源稀缺 → 等级可数 → 制度性施压。**
凡是不具备这三件套的类型，卡的都不是 prompt 措辞，是槽本身。

## 4. 逐分类取样与判定

档位定义：**A = 原生适配**（九槽填得满，只需换词）；**B = 改素材**（不改代码，调配置与素材即可）；
**C = 缺维度**（要新增一类世界观/结构维度）；**D = 骨架冲突**（槽的方向与类型相反，改 prompt 无用）。

### 4.1 都市高武 —— A

| 书 | 核心机制 | 九槽对位 |
|---|---|---|
| 《我在精神病院学斩神》 | 凡人六境（盏/池/川/海/无量/克莱因，按精神力）+ 神明四阶；金手指＝意识里的精神病院，收治神明→抽技能→可复刻给队友 | S1 六境 ✔ S2 精神力可数 ✔ S5 采集源＝"收治的神明"，采一次惹一个 ✔ |
| 《我不是戏神》 | 赤星灾厄后文明崩坏；以戏入道，生旦净末丑对应神通；观众期待值驱动 | S1 ✔ S6 单元＝一场戏 ✔ S7 逼法需换词（期待值→立卷） |
| 《异兽迷城》 | 都市表象，万分之一是真人类；主角觉醒幸运/异能 | S5 弱（金手指不采集）→ 需走 B 的"被动型金手指" |
| 《诸神愚戏》 | 邪神靠人类情绪喂食；主角用规则而非蛮力求生 | S7/S8 极强（规则博弈）S2 弱（不靠数值压人） |

判定：**A**。境界体系、组织（守夜人按城市分小队）、资源全部现成。唯一要改的是词汇——"灵光透体几层"对都市高武要写成"禁墟几阶"。

### 4.2 传统玄幻 —— A（原生）

| 书 | 核心机制 |
|---|---|
| 《夜无疆》辰东 | 永夜世界，**无金手指**，凭狠劲；宿命轮回、天地秘辛 |
| 《玄鉴仙族》季越人 | 残魂附古镜，**器灵视角**；家族群像，种田+争霸，资源生存，无系统 |
| 《剑烛大荒》 | 传统热血：天骄争锋、上古遗迹、种族大战，升级链条清晰 |
| 《凡骨》 | 凡人流，无系统无逆天金手指，硬扛修行界 |

判定：**A**，这就是本工作流的原生土壤。但要标一条：**"无金手指"是合法的**——
《夜无疆》《玄鉴仙族》《凡骨》《冒姓琅琊》四本高口碑作品全部无外挂。我们的 `goldenFinger` 是可填项，不是必填逻辑。

### 4.3 玄幻脑洞 / 苟道流 —— B

| 书 | 核心机制 |
|---|---|
| 《开局长生万古，苟到天荒地老》 | 苟道流：躺平等仇人死 |
| 《系统赋我长生，我熬死了所有人》 | 长生流：靠时间耗死对手 |
| 《这个游戏不对劲，我挖矿成神》 | 游戏降临+职业+挖矿升级 |
| 《洪荒，我把怨念当功德，大道懵了》 | 反套路：功德/怨念互换 |

判定：**B**。S1–S4 全在，卡的是 S5 与 S7：
- S5 要允许"**被动型金手指**"（长生、苟、签到），现在四个维度（获取/机制/交互/进阶代价）隐含假设金手指是主动使用的。
- S7 逼法五档是"施压者按程序升级"，苟道流的压力是"**我不惹事，事来找我**"——施压方存在，但程序阶梯不成立。

### 4.4 东方仙侠（凡人流 / 资本流） —— B，且意外地近

| 书 | 核心机制 |
|---|---|
| 《没钱修什么仙?》熊狼狗 | 昆墟界（地上 36 层 / 地下 18 层）；**灵根可租赁、功法是付费网课、法力贷**；金手指＝黑色羽书 + AI 监工"卷灵"，懈怠遭神魂惩戒 |
| 《苟在武道世界成圣》 | 苟道流教科书，一击必杀不留后患 |
| 《同学们选武侠仙侠，我选洪荒世界》 | 选择流 + 信息差碾压 |
| 《聚宝仙盆》 | 凡人流 |

值得单独指出来：**《没钱修什么仙》的"法力贷 + 复利 + 催收"与我们这本书的"生死契 + 月息两成复利"是同一个机制**。
它能承载我们的 S3/S7 全套——逼法五档（关心→标价→立卷→债务→摊牌）在债务修仙里是**字面成立**的。
判定：**B**，只需把 S1 的"升级代价"从灵石改成钱。

### 4.5 悬疑脑洞 / 规则怪谈 / 无限流 —— D

| 书 | 核心机制 | 结构 |
|---|---|---|
| 《十日终焉》 | 十日一轮回、十二生肖死亡游戏；**无异能、不靠数值压人**，全靠观察与人性博弈 | 串珠式：主线串副本 |
| 《诡舍》 | 诡舍为固定中转站，九扇血门连不同副本；灰日污染末日背景 | 串珠式 |
| 《规则怪谈：无所谓，系统会出手》 | 反差松弛流，别人背规则主角拆招 | 串珠式 |
| 《怪谈直播间》 | 直播型怪谈 + 无限推演天赋 | 串珠式 |

判定：**D**。三条硬冲突：

1. **S1/S2 整个不适用。** 《十日终焉》的主角"没有强力异能"，全书不靠等级碾压。硬刻度在此类型里是**负资产**（写了反而降智）。
2. **S7 的五档方向相反。** 我们的压力来自"施压者按程序升级"；规则怪谈的压力来自**规则本身**——没有施压者，没有关心/标价/立卷。
3. **S6 反而完全对得上。** "单元 = 一段对峙局面"＝一个副本；"卷 = 世界和他都换了状态"＝一次世界观揭示。结构层能用。

所以这是**"结构层能用、素材层全废"**。要接这个类型，得做一整套平行的世界观维度：规则条目表 + 矛盾点 + 违规后果 + 生路线索。**不是加一格，是加一套。**

### 4.6 历史古代 / 历史脑洞 —— C，但另一半极强

| 书 | 核心机制 |
|---|---|
| 《冒姓琅琊》东周公子南 | 南齐；**无系统、无金手指、无记忆继承**；唯一外挂是文史功底；经学辩论破局；每章附史料注释 |
| 《皇家金牌县令》 | 历史轻松向 |
| 《水浒：在下陆谦，梁山加钱哥》 | 历史同人 |

判定：**C**。缺 S1/S2（无力量刻度），但**另一半强到意外**：

| 九槽 | 《冒姓琅琊》对位 |
|---|---|
| S4 施压机构 | 门阀 + 边军"过所"盘查 + 御史中丞，**职权凭证清晰** |
| S7 逼法五档 | 郡学辩论（立卷）→ 谱牒核查（取证）→ 当场露馅被诛（摊牌）——**字面成立** |
| S8 交手六类 | 清谈辩难＝取证，冒名＝设局，认祖＝认账 |
| S3 生死资源 | 户籍（"过所"）比灵石更硬：没有它就是北谍，当场处决 |

**它缺的只有 S1/S2。** 也就是说：历史文要接，得允许"**等级表换成官阶/门第/声望三轨，且不提供硬刻度**"。

### 4.7 游戏 / 科幻末世 —— C

| 书 | 核心机制 |
|---|---|
| 《游戏入侵：抢男女主机缘会上瘾诶》猫不秃 | 游戏入侵 + 穿书反派自救；S 级天赋【盗神】可偷技能/属性/物品；信息差 + 时间管理滚雪球 |
| 《公路求生榜一说她要走到公路尽头》 | 公路求生 |
| 《综网：我铸就万千伟业》 | 综网 |

判定：**C**。S5 极适配（盗神＝采集型，采的时候必然惹上原主，和我们这本书一模一样）。
缺的是 S1 的实现形态：游戏类的等级是**面板 + 技能树**，不是"每级卡点 + 升级代价"的阶梯表。

### 4.8 西方奇幻 / 领主种田 —— B

《领主：我在苦痛世界，养成少女》：种田 + 西幻 + 多种族，慢热。判定 **B**：S3 强（领地/人口）、S4 可写（领主权），S1 换成位阶即可。

### 4.9 女频全部 —— D

| 分类 | 代表作 | 核心机制 |
|---|---|---|
| 星光璀璨（发疯文学） | 《癫，都癫，癫点好啊》 | 穿书即疯癫，拒炮灰命运；**爽点不在变强，在"我疯故我在"** |
| 豪门总裁 | 《睁眼！太子爷的恶毒女友重生了》《十诫锁心》 | 重生+穿书+恶女+疯批；强制爱 |
| 古风世情 | 《惹金枝》 | 文笔/剧情/人设无短板，影视版权已售 |
| 年代 | 《重生七零：不做冤种前妻》 | 空间囤货 + 搞钱 + 甜宠 |
| 宫斗宅斗 | 《不是疯批反派吗？怎么红眼要抱抱》 | 穿书+误睡反派+红眼病娇 |

判定：**D**，且是最彻底的一档。四条理由：

1. **S1/S2/S3 全缺。** 女频不靠战力刻度，"推荐额"这种生死资源不存在。
2. **S7 方向错。** 女频的压力是**名分与关系**（谁的妻子、谁的女儿、谁的人），不是法律程序。逼法五档（关心→标价→立卷→债务→摊牌）在宅斗里最多用到第二档。
3. **S5 常为空。** 空间/系统是"便利设施"，不是"采集即惹祸"的麻烦源。
4. **S6 勉强能用、S9 要重写。** 两级结构与节拍库是通用的（这两层不分男女频），但正文链的"爽点五型 + 章末具体钩子"是按男频写的。发疯文学的爽点是**情绪爆破**，不是"打脸/收获/揭秘/升级/被认可"里的任何一类。

## 5. 汇总

| 档 | 类型 | 占男频主分类 | 代价 |
|---|---|---|---|
| **A 原生** | 都市高武、传统玄幻 | 约 30% | 只换词 |
| **B 改素材** | 玄幻脑洞/苟道流、东方仙侠、西方奇幻 | 再 +25% | 改配置，不改代码 |
| **C 缺维度** | 历史古代/脑洞、游戏体育、科幻末世 | 约 20% | 各加一类维度（等级表换轨 / 面板化） |
| **D 骨架冲突** | 悬疑脑洞、悬疑灵异、**女频全部** | 约 35%（含女频） | 改 prompt 无用，需平行模板族 |

**结论一：这套工作流的原生适配面，是"有力量刻度 + 有稀缺资源 + 有制度压迫"的男频高武/玄幻，约占男频主分类一半，占两站全部分类不到三分之一。**

**结论二：卡住我们的不是 prompt 措辞，是槽的方向。**
九槽里 S1/S2/S3/S5/S7 全部预设了"力量可数、资源稀缺、施压者按程序升级"。这些假设在悬疑、历史（部分）、女频里是反的。
**在 D 档类型上继续调 prompt，只会把书写成"套着悬疑皮的高武文"** —— 这正是作者说的"偏科生"在更大的尺度上重演。

**结论三：结构层是通用的，素材层不是。**
S6（卷/单元）、节拍库十套、S9 的章末钩子，在两站全部 14/19 类里都成立——因为它们管的是"节奏形状"，与题材无关。
**所以扩展应该沿"素材层"做，不该动结构层。**

## 6. 如果要做兼容，最小改动顺序

按"改动量 ÷ 收益"排：

| 序 | 改什么 | 解锁 | 性质 |
|---|---|---|---|
| 1 | `goldenFinger` 明确可空，且分辨"主动采集型 / 被动伴随型" | 玄幻脑洞、苟道流、历史考据流 | 改字段语义，不加槽 |
| 2 | S1 等级表的"等级名"允许换成非战力轨（官阶 / 门第 / 位阶 / 面板） | 历史、西方奇幻、游戏 | 改提示词，不加槽 |
| 3 | S7 逼法五档标记为"**制度型**专用"，另给"关系型 / 规则型"两套等价档位 | 女频、悬疑 | 加枚举，不改结构 |
| 4 | 悬疑/规则怪谈用平行世界观维度（规则表 + 矛盾点 + 违规后果） | 番茄当前增速最快的赛道 | **新增模板族**，工作量最大 |

第 1、2 条是纯配置改动，随时可做。第 3 条要动 `PRESSURE_TAG` 的枚举，得同步改校验。第 4 条不建议现在做——它是另一个产品。

## 7. 一份如实提醒：工作流形态与番茄节奏的错配

这条不改代码，但影响"能不能投"。

番茄的公开口径是"3000 字定生死"、完读率 >15%、日均阅读 >1 小时（第三方转述，非官方数据）。
