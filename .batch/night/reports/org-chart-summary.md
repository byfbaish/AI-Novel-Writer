# 组织架构摘要（发群用，200 字级 · 11-15 修订 v2）

主人居中，两翼并行：

- 左：**大管家**（大肥鱼主身，只在主人私聊）——管路由、时限、规则、对外沟通，不判技术、不替主人拍板
- 左：**项目管家**（大肥鱼在群里的分身，群 admin）——发起回合、按口径传达、核对齐套、控场；**不确认、不承诺、不裁量、不代答**
- 右：总负责人——管节奏、派卡、验收终审
  其下：产品经理（规格）、QA（首验判定）、金牌编辑（文学门禁）、developer（环境工具链取证）、workbuddy 联络人、豆包联络人（转任务收回执）
  外部：WorkBuddy / 豆包，只能经联络人调动

**身份铁律**：说「大肥鱼」必须标层（大管家 / 项目管家）。「找大肥鱼确认」默认指大管家；群里的分身只能转呈（`bridge\to-owner`）并声明"已转大管家，不要等我"，不得代答。凡「已确认/已拍板」指不出大管家或主人原话位置的，一律无效。

汇报：下属五岗 → 总负责人 → 主人；大管家 → 主人，另收全员超时与阻塞。跨层直报只两种：不裁决就卡死、安全风险；可经大管家通过 IM 联络主人，大管家只做通道、不裁决；主人未回复前保持阻塞，不自动降级。

指令：主人 → 大管家 / 总负责人（并行）→ 下属 → 联络人 → 外部方。
