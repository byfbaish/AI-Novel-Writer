# 争议提交（唯一模板）

适用：bot 之间有分歧，或对卡片口径/验收线/规则有异议。群里只发这一份，不各写一版。

```
【争议】<一句话分歧点>
【各方观点】@A：… | @B：…（只写主张，不写过程）
【依据】文件/行号/日志/文档链接（没有依据写「无」）
【影响】不解决会卡住什么、影响谁、是否阻塞今晚
【可逆性】可逆 / 不可逆（不可逆的必须等主人）
【建议】<一条，带选项 A/B，标明推荐哪个>
【待拍板】@<要裁决的人> 需要他回答的具体问题
```

规则：
- 一条争议只写一条摘要，**总轮次 2 轮**内收口；超了自动转「已查/未解/建议」留待主人裁定。
- 长篇依据走文件（`.batch/night/essays/` 或 `reports/`），群里只留结论行 + 文件路径。
- 收口人：大肥鱼（合并成一条升级包）。
- 裁决口径（负责人 21:13 补）：
  - **可逆事项** → 总负责人按建议拍板，群里留一行结论即可，不必等主人。
  - **不可逆事项**（改已发布版本、动他人仓库、删数据）→ 必须先走主人；不允许「先把建议填了就动手」。
