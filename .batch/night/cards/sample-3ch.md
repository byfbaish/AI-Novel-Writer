# 开篇 3 章样稿 · 规格卡（B 类草稿，落 staging）

> 状态：待裁定（2026-11-14）· 出稿：产品经理
> 只写三件事：沿用哪个项目与设定 / 三章各章末要留下什么具体问题 / 报告首行记 provider+model id。
> **不许出现风格形容词**（见 §4 禁用清单）。风格由对标表 v2 的差异决定，不由本卡决定。

## 1. 背景

市场质量三组判据里 G-A（好不好看）目前没有任何读数。要拿到读数，先得有「可被盲评的样稿」；样稿必须与对标表同题材，否则盲评表打出来的分无法解释。

## 2. 目标

产出**同一项目、同一设定**下连续 3 章样稿 + 一份可核报告。判据只看「章末有没有留下具体问题」，不看文笔。

## 3. 功能描述（执行方要做的三件事）

### 3.1 沿用哪个项目与设定

| 项 | 取值 |
|---|---|
| 项目 | **新建**「开篇试样」，不复用任何历史项目（历史项目带旧 prompt 残留，会污染归因） |
| 平台节奏画像 | `番茄向`（不是空值；空值会让形态日志整段消失） |
| 频道 / 题材 | **待主人一句定**：建议 `女频 · 古代言情`（与对标表 v1 同一张女频阅读榜，同题材才可比）；若定男频/都市/悬疑，**先换榜重取对标表，再写样稿** |
| 设定 | 主角、反派、初始困境三行，由执行方在建项目时一次写死并抄进报告；三章内不许改设定 |
| 生成方式 | 走产品自带链路逐章生成（不手写、不外部模型代写），模型与参数用默认值 |

### 3.2 三章各章末要留下什么具体问题（唯一硬判据）

每条都必须能在**章末最后 200 字**内被指认；指认不了就是没留下。

| 章 | 章末必须留下的东西 | 判定方式 |
|---|---|---|
| 1 | ① 读者能一句话说出**主角此刻最怕失去什么**；② **谁在逼他**（有名有姓的对手）；③ 一个**具体时间或数量**的倒计时（如「三天后」「三日后」） | 三条各自在章末找得到原句；缺一条记「无」 |
| 2 | ① 第一个小目标**已闭环**（做成或失败，结果写清）；② 抛出第二个障碍，且带**明确对手 + 截止时间** | 闭环有结果词（成了/没成/被夺走）；障碍必须含人名与时间 |
| 3 | ① 主角做出一次**不可撤回**的选择；② 该选择的**代价已可见**（失去什么）；③ 留下一个**下一章必须回答的信息问题**（不是情绪，不是感慨） | 三条逐条指认；「代价」必须是具体东西，不是心情 |

### 3.3 报告首行记 provider + model id

报告第一行必须是机器可核的原文，不许改写、不许只写「默认模型」：

```
provider: <provider id> · model: <model id> · run: <run id 或 trace id>
```

- 三者任一拿不到就写 `unknown` 并说明原因；**不许留空**。
- 第二行起才是读数：每章字数、章末最后 20 字原文、三条判据逐条「有/无」+ 支撑原句（≤30 字）。
- 产物：`.batch/night/staging/opening-3ch-report.md`；正文落在项目里，不复制进 staging。

## 4. 明确不做

1. 不写、不改任何风格形容词（禁用：`文风`、`笔触`、`节奏感`、`番茄味`、`AI 味`、`细腻`、`流畅`、`有画面感` 及同类词）。
2. 不做「写完再找理由」：本卡不预设结论，判据只有 §3.2 三条。
3. 不改 prompt、不改代码、不改配置模板。
4. 不重写、不润色（一次生成就是样稿；人工改过的稿子失去盲评意义）。
5. 不写信号（`signals\lead\` 不在 watch 列表）。

## 5. 验收标准

1. 项目建出、平台画像=番茄向、三行设定抄进报告（截图或文本亦可）。
2. 三章齐全，且 §3.2 的 8 个检查点逐条给出「有/无」+ 支撑原句；**「无」也要写**，不许合并成一句「基本符合」。
3. 报告首行含 provider 与 model id 的真实取值。
4. 报告里风格形容词出现 0 处（grep §4 禁用清单）。

## 6. 待确认（交负责人/主人）

1. 频道与题材（决定对标表是否要换榜）——**这条不定，本卡不能派**。
2. 章数是否就 3 章（若要对标「3 章内小目标闭环」，3 章是下限，不建议再减）。
3. 样稿是否进盲评表 v1 的同一轮（进则需 10 行评分，不进则只作素材）。

## 三、章末钩子的形态（4 处实测，含 3 章连读）

**A. 行动承诺 + 具体时点**（惹金枝 第 001 章末）
- 女主与男主谈成交易「成了！」，约定「明日巳时」见面、劫法场救人出城、送到禹县西城门外长亭交给指定人。
- 章末没有疑问句，落在**行动安排 + 具体时点 + 下一个动作**。

**B. 情绪/身世铺垫（弱钩子）**（惹金枝 第 002 章末）
- 回忆养育之恩、「心甘情愿付出代价」、脑补对方身份被揭破时的场面，收在「想了想那个场面，笑出声来」。
- 这章**没有推进新事件**，属于动机交代章的软收尾——说明头部作品也允许一章做纯铺垫，但只做一次。

**C. 承诺 + 相认 + 插科打诨**（惹金枝 第 003 章末）
- 牢里见家人：满门抄斩（连七岁以下、九十以上都不放过），女主在地图上添数笔、折起，留一句「两日后见」；与生母相认（画像伏笔）；收尾是狱卒插科打诨「五天后再来看您」。
- 章末 = **硬倒计时「两日后」** + 情感落点 + 一点轻松调子。

**D. 强情节冲击**（帝王娇宠 第 01 章末）
- 女主被皇帝强吻、失去意识，最后一句落在身体感。
- 章末 = **情感/亲密场面硬钩子**，没有任何行动计划。

**E. 对手视角猜疑 + 当章小目标已闭环**（二凤伴读 第 1 章末）
- 当章小目标达成：小孩把受伤的二公子拉去上药、还盘算去厨房弄吃的；末段切到二公子心里：「不知道他到底是真心疼自己，还是为了留在府中而做出来的表现」。
- 章末 = **小目标闭环（结果已落地）+ 对手/旁人的新疑问**。
