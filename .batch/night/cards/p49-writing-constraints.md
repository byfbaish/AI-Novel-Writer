## 1. 为什么要这个

P47 三章结构层 **3/8**：八条里失败的 5 项，需要的信息都在章里，但都落在**章末 200 字窗口之外**，末段是氛围/悬念收尾。上一轮同一张八条是 8/8。判据没错、执行方没偷工，是**生成时没把八条当写作约束**。

所以现在缺的不是更好的判据，是把八条翻成「写的时候照着做」的句子。

## 3. 要写什么

对八条**每一条**给一段，格式固定三行：

```
## <章号>-<序号> <检查点名称>
必须出现：<一句祈使句，写「末段里要有什么」，不解释为什么>
反例：<一句「写成这样就判无」，取自 P47 实际失败的写法>
```

硬要求：

1. **「必须出现」要能让写作者直接照做**——写的是末段里必须有什么（人 + 动作 + 具体物 + 时间/数量），不是复述判据名。例：不要写「必须体现倒计时」，要写「末段里要出现一个带数字和时点的句子，说明这件事必须在这之前办完」。
2. **反例必须来自 P47 的真实现状**（窗外 + 末段写氛围），不要编。
3. 八条之外**只加一条**（编号 G1）：「关键道具每次挪位必须有一句交代它怎么到这里的」。
4. 末尾加一节「自检清单」：8+1 条压成一句一句的勾选问句，供执行方写完自查用。
5. 全文 ≤ 90 行。写给「写小说的人」看，不写给程序看；**不要写提示词模板、不要写代码、不要写 JSON**。
