# 文学层三检查项 · 卡面草案 v1

> 用途：补规格卡 §3.2 八条**管不到**的那一层。八条判「章末有没有留东西」，本表判「留下的东西站不站得住」。
> 输出只有两态：**有 / 无 ＋ 引句**。不给分、不给等级、不拦生成（advisory），命中即返修。
> 判定人：金牌编辑。QA 不复核本表（避免重复判）。状态：草案，待主人定是否入卡。

## 检查项 A：设定打架（同一事实两说）

**怎么判**：把本章内出现的可核事实（生死、时间、地点、人物关系、物件归属、数量）列出来，同一事实出现两种说法且不能互相解释，判「有」。

**可指认的失败例句**（取自 `sample-3ch` 实测）：
- 第1章 段3「贵人没死，可拦药的人成了替罪羊」 vs 段21「贵人死了，罪名落在我头上」——同一桩三年前旧案，一处说活着、一处说已死。
- 第2章 段7「暗格是空的」 vs 段9「指尖碰到一张薄纸」 vs 段10「有人试过撬，没撬开，就用火烧」——残账到底在哪一层，读者读不出。

**合格长什么样**：两种说法能互相解释（如「贵人当时没死，三日后才死」），或明写是两个不同对象。

## 检查项 B：钩子所依托的物件/信息，前文有没有出现过

**怎么判**：取章末最后 200 字（`countDraftUnits` 口径）内的悬念落点，指认它依赖的人、物、信息；该对象若在**本章之前**（含本章前文）零出现，判「有」。

**可指认的失败例句**：
- 第3章 段52「那半枚虎符，到底交到了谁手上？」——虎符前三章从未出现，段47 只提铜钥匙，「半枚」更无从理解。

**合格长什么样**：落点依赖前文已实写过的东西（如「父亲真正要她找的，不是账册」——账册三章都在）。

**与八条的关系**：八条第 8 项判「有没有信息问题」，字面可成立；本项判「这个问题读不读得懂」，两层分别记。

## 检查项 C：正文混入策划语言

**怎么判**：正文（人物语言、叙述、内心）出现圈内策划词或元叙述——小目标、爽点、钩子、检查点、读者、卖点、闭环——判「有」。作者旁注、章节卡不算正文。

**可指认的失败例句**：
- 第2章 段37「第一个小目标，没成。」——「小目标」是策划词；同段还连报「账册没拿回／第二个麻烦来了」，读起来像向读者汇报检查点。
- 第2章 段38「必须在今夜想出一个让谢贵妃不敢动手的理由」——把下一章许成「想主意」，属叙述者对读者的承诺，不是人物语言。

**合格长什么样**：结果用动作或事实收（「她没能拿回账册。手在抖。」），不用名词化的进度词。

## 输出格式（每项一行，没有就写「无」）

```
A 设定打架：有 ｜ 第1章 段3「贵人没死」vs 段21「贵人死了」
B 钩子无铺垫：有 ｜ 第3章 段52「那半枚虎符」
C 策划词：有 ｜ 第2章 段37「第一个小目标，没成」
```

## 边界

1. **不做**：人物弧光、节奏快慢、卖点位置、对话好不好听——这四项不给阈值，只出修改方向（见 `reports/edit-gate-v1.md` 对应条目）。
2. **不机读**：三项全部人工判，不允许做成自动闸（`market-quality-acceptance.md` 边界 2：钩子机读会奖励 AI 腔）。
3. **不拦生成**：命中即返修，返修提请负责人派卡，我不派卡、不改稿。
4. **不评美丑**：只判「有没有」，不判「写得好不好」。
