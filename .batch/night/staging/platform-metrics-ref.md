## 2. 口径定义（可直接引用）

| 指标 | 确切口径 | 常见误读 |
|---|---|---|
| 追更人数 | 当天读过「最近三天更新章节」的**人数** | 断更三天后此数会趋近 0 —— 这是口径造成的，不是读者流失 |
| 追读率 | 追更人数 ÷ 当天阅读人数 | **官方不公布及格线**，任何「达标线」都是经验值 |
| 十万字完读率 | 后台默认展示的档位指标（读到十万字仍留存的比例） | 与「追读率」不是同一分母，两者不可互换比较 |
| 在读 | 过去 **14 天**读过该书的总人数 | 比「追更」宽得多，不能当活跃度看 |
| 留存趋势 | 同一本书**连续四周**的同指标变化 | 单日绝对值受推荐位、更新时点影响，不可做判据 |

## 3. 参考区间（全部为经验值，非规则）

| 区间 | 数值 | 怎么用 |
|---|---|---|
| 追读率安全线 | ≈25% | 只在讨论「要不要查前几章」时当触发话题，不当门槛 |
| 追读率健康线 | ≈40% | 同上 |
| 十万字完读率行业观察均值 | 16–17% | 同上 |
| 十万字完读率警戒 | <10% 建议回查前五章 | 这是**建议动作**，不是判定标准 |

题材差异极大：同一数值在不同分类下的含义完全不同，本文不给任何跨题材换算。

## 4. 使用规则（硬）

1. **不可入判据。** 本文任何数字不得写进卡面判据、验收门、首验报告；卡面若引用外部数据，必须写明来源＋口径，没写就判 **N/A**（该条规则与「N/A 时单列『外部依据缺失』、八条分母恒为 8」的要求，已由项目管家写入 SOP 正本 `.batch/night/staging/research-cost-sop-v1.md` §3；冲突时以 SOP 为准）。
2. **趋势优先于绝对值。** 要判好坏，看同一本书连续四周的同指标走势；单点读数只能当「值得看一眼」的信号。
3. **口径先于数字。** 引用前先确认是哪个口径（追更 ≠ 在读 ≠ 追读率分母），口径不同则不可比。
4. **待交叉验证。** 在拿到 2–3 个独立来源印证之前，本文 §3 的数字只能出现在讨论里，不能出现在结论里。
